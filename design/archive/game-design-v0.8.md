## 3. กลางวันและกลางคืน

หนึ่งวันมี 2 เฟสที่เล่นต่างกัน: **กลางวันเตรียมตัว** · **กลางคืนแย่งชิง** ทุกเฟสเริ่มด้วยการสุ่มอีเวนต์ 1 อย่าง (ข้อ 3.3)

### 3.1 กลางวัน: ไม่มีการต่อสู้

| ขั้น | เกิดอะไร |
|---|---|
| ① **ประกาศอีเวนต์กลางวัน** | สุ่ม 1 อีเวนต์ แจ้งทั้งห้อง |
| ② **เลือกพื้นที่ + กิจกรรม** | เลือกพร้อมกันแบบลับ (30 วิ) |
| ③ **เปิดเผย** | ทุกคนเห็นว่าใครอยู่พื้นที่ไหน คนที่อยู่พื้นที่เดียวกันเห็นคลาสและ HP ของกันและกัน |
| ④ **ทำกิจกรรม** | ได้ผลของกิจกรรมที่เลือก ห้ามโจมตีกันทุกกรณี |

| กิจกรรมกลางวัน | ผล |
|---|---|
| **เก็บของ** | ทอยเก็บทรัพยากรของพื้นที่ (ข้อ 4) ได้คนเดียว ไม่ต้องแบ่ง |
| **สอดแนม** | ดูมานาและการ์ดในมือ (จำนวนใบ) ของทุกคนในพื้นที่เดียวกัน + รู้ว่าพื้นที่ไหนจะมีทรัพยากรมากที่สุดคืนนี้ |
| **พักฟื้น** | ฟื้น HP 25% |
| **ธุระโบสถ์** | (เฉพาะที่โบสถ์) แลก Command Seal ด้วยมานาหรือรับเควส (ข้อ 9.1) |

กลางวันจึงเป็นช่วงสะสมของ อ่านเกม และวางแผนว่าคืนนี้จะไปแย่งที่ไหนกับใคร

### 3.2 กลางคืน: ต้องต่อสู้แย่งทรัพยากร

| ขั้น | เกิดอะไร |
|---|---|
| ① **ประกาศอีเวนต์กลางคืน** | สุ่ม 1 อีเวนต์ |
| ② **เลือกพื้นที่** | เลือกพร้อมกันแบบลับ (30 วิ) |
| ③ **เปิดกองทรัพยากร** | ทุกพื้นที่ทอยกองทรัพยากรของคืนนี้ (ประมาณ 2 เท่าของกลางวัน) แสดงให้ทุกคนเห็น |
| ④ **แย่งชิง** | ใครอยู่พื้นที่เดียวกันต้องสู้กัน (ข้อ 7) |
| ⑤ **แจกทรัพยากร** | ผู้ชนะของแต่ละพื้นที่ได้กองทรัพยากรทั้งหมด |
| ⑥ **อัญเชิญใหม่** | Master ที่ Servant ตายเลือกจ่าย Command Seal อัญเชิญใหม่ (ข้อ 8) |

- **อยู่คนเดียว** → ได้ทั้งกองโดยไม่ต้องสู้
- **2 คน** → ดวลกัน ผู้ชนะได้ทั้งกอง ผู้แพ้ไม่ได้อะไร
- **3 คนขึ้นไป** → **ตะลุมบอน** ทุกคนสู้พร้อมกันในสนามเดียว (ข้อ 7.1)
- **การหลบ:** ไม่มีท่าทีซ่อนตัวแล้ว ทางเลี่ยงการสู้มีแค่ Command Seal "หนี", การ์ดม้วนคาถาเคลื่อนย้าย/ศิลาเขตแดน หรือสกิล Assassin ซึ่งทั้งหมดทำให้ไม่ได้ทรัพยากรคืนนั้น
- ไม่เลือกภายในเวลา = พื้นที่เดิม

| คำสั่งด่วนจากโบสถ์ | รับเควสได้ฟรีไม่ต้องมัดจำ |

| ข่าวลือ | เปิดเผยคลาสของคนที่มีมานามากที่สุด |

| กลางคืน | ผล |
|---|---|
| จันทร์เต็มดวง | ทุกการทอย +1 |

| คืนเลือด | ผู้ชนะยึดมานาทั้งหมดของผู้แพ้ (แทนครึ่งหนึ่ง) |

## 4. พื้นที่ในเมืองฟุยุกิ (5 พื้นที่)

| พื้นที่ | ได้อะไร (ทอย 1d6) | ลักษณะ |

| วัดริวโด | มานา 2–7 | เลย์ไลน์ มานาสูงสุด คนชอบมา |
| ป่าไอนซ์เบิร์น | มานา 1–4, ฟื้น HP 10% | ต้นไม้บังตา: กลางคืนผู้ป้องกันได้ DEF +1 |

| โรงเรียนโฮมูระฮาระ | มานา 1–6 | กับดัก ทอย 1 = เสีย HP 10 |

ตัดบ้านเอมิยะ สะพานฟุยุกิ และย่านมิยามะออก

### รับประกันการเจอกันทุกเฟส
- ผู้เล่น 8 คนลง 5 พื้นที่ อย่างน้อย 1 พื้นที่ต้องมี 2 คนขึ้นไปเสมอ (หลักรังนกพิราบ)
- เมื่อผู้เล่นเหลือน้อยลง **เขตแดนหดตัว**: จำนวนพื้นที่ที่เปิด = ผู้เล่นที่เหลือ − 1 (ขั้นต่ำ 2) จึงยังมีคู่ที่เจอกันทุกเฟส
  - เหลือ 6 คน → 5 พื้นที่ · 5 คน → 4 · 4 คน → 3 · 3 คนหรือน้อยกว่า → 2
- พื้นที่ที่ปิดสุ่มเลือกและประกาศล่วงหน้า 1 เฟส ⚠️
- รับประกันนี้สำคัญกับ **กลางคืน** เพราะเป็นเฟสที่ต้องแย่งชิง กลางวันการเจอกันให้แค่ข้อมูล

### การเปิดเผยชื่อจริง
- **ใช้ Noble Phantasm ครั้งแรก** → ทั้งห้องเห็นชื่อจริง สกิลทั้งหมด NP จุดอ่อน และพื้นที่ถนัด/ไม่ถนัด
- ก่อนถูกเปิดเผย ผู้เล่นอื่นเห็นแค่คลาส ค่าสถานะ และ "สกิลที่เคยใช้ต่อหน้าเขา"
- จุดอ่อนมีผลเฉพาะกับคนที่รู้ชื่อจริงแล้ว เมื่อเปิดเผยด้วย NP ทุกคนรู้
- การ์ด "บันทึกวีรชน" (ข้อ 10) เปิดชื่อจริงของเป้าหมายให้ผู้ใช้คนเดียวรู้
- ทำให้ NP เป็นการตัดสินใจจริงจัง: ใช้แล้วแรง แต่เสียความลับ

### หนึ่งการต่อสู้
1. ทั้งคู่ทอย 1d6 + AGI สูงกว่าได้สิทธิ์ "เปิดท่าทีหลัง" ในรอบสุดท้าย ⚠️
2. ทุกรอบ ทั้งคู่เลือกท่าลับพร้อมกัน จ่ายมานาทันที
3. Server ทอยลูกเต๋า แสดงแอนิเมชัน คิดดาเมจ
4. สูงสุด 3 รอบ หรือจน Servant ฝ่ายหนึ่งตาย
   ครบ 3 รอบแล้วไม่มีใครตาย: ฝ่ายที่เหลือ HP (เป็น %) มากกว่าชนะ ได้ทรัพยากร ผู้แพ้ถอยไปมือเปล่า ⚠️
5. ผู้ชนะ (ทำให้อีกฝ่ายตาย) ยึดมานาครึ่งหนึ่งของผู้แพ้ และการ์ด 1 ใบสุ่ม
6. ผู้เล่น 3 คนขึ้นไปในพื้นที่เดียว: ใช้กติกาตะลุมบอน (ข้อ 7.1)
7. ทุกการทอยในการต่อสู้ได้รับผลจากพื้นที่ถนัด/ไม่ถนัด (ข้อ 6.1)


### 7.1 ตะลุมบอน (3 คนขึ้นไปในพื้นที่เดียวกันตอนกลางคืน)

ทุกคนอยู่ในสนามเดียว ทุกรอบเลือกพร้อมกัน ทุกคนเป็นศัตรูของทุกคน

**หนึ่งรอบ (เลือก 20 วิ)**
1. ทุกคนเลือกลับๆ: **ท่า** + **เป้าหมาย** (ท่าป้องกัน/หนีไม่ต้องเลือกเป้า)
2. เปิดพร้อมกัน แสดงลูกศรว่าใครเล็งใคร
3. Server ทอยทุกลูกพร้อมกัน แล้วคิดดาเมจทั้งหมด **พร้อมกัน** (ตายพร้อมกันได้)
4. คนที่ HP หมดออกจากสนาม คนที่หนีสำเร็จออกจากสนาม

**กติกาเฉพาะตะลุมบอน**

| เรื่อง | กติกา |
|---|---|
| จำนวนรอบ | 3 รอบ (5 คนขึ้นไป = 4 รอบ) หรือจนเหลือคนเดียว |
| การป้องกัน | ทอยป้องกันครั้งเดียวต่อรอบ ใช้กับทุกการโจมตีที่เข้ามา · คนที่ไม่ได้เลือกป้องกันใช้แค่ค่า DEF (ไม่ทอย) |
| ถูกรุมหลายคน | ถ้าถูกเล็ง 2 คนขึ้นไปในรอบเดียว ได้ +1 ลูกเต๋าป้องกัน และการโจมตีจากคนที่ 3 เป็นต้นไปดาเมจลดครึ่ง (กันการรุมจนตายทันที) ⚠️ |
| ท่าโจมตีวงกว้าง | NP บางตนโดนหลายเป้า (ตารางล่าง) ดาเมจแต่ละเป้า −25% |
| หนี | ทอย 1d6 + AGI ต้องชนะคนที่ AGI สูงสุดในบรรดาคนที่เล็งเรา (ไม่มีใครเล็ง = หนีสำเร็จแน่) |
| ฆ่าได้ | คนที่ทำดาเมจสุดท้ายได้มานาครึ่งหนึ่งของผู้ตายและการ์ด 1 ใบ ถ้าทำดาเมจพร้อมกัน คนที่ทำดาเมจมากสุดในรอบนั้นได้ |

**ใครได้กองทรัพยากร**
- เหลือคนเดียวในสนาม → ได้ทั้งกอง
- ครบรอบแล้วยังเหลือหลายคน → นับ **คะแนนตะลุมบอน** = ดาเมจที่ทำได้ทั้งหมด + 20 ต่อการฆ่า 1 ครั้ง คะแนนสูงสุดได้ทั้งกอง คนอื่นได้ 0 (เสมอ → HP ที่เหลือเป็น % มากกว่าชนะ)
- จึงไม่คุ้มที่จะป้องกันอย่างเดียวรอให้คนอื่นตีกัน ต้องลงมือด้วย

**NP วงกว้าง**

| Servant | โดน |
|---|---|
| Gilgamesh (Gate of Babylon), EMIYA (UBW), Iskandar (Ionioi Hetairoi) | ทุกคนในสนาม |
| Artoria (Excalibur), Siegfried (Balmung), Gilles (Prelati's Spellbook) | 2 เป้า |
| ที่เหลือ | 1 เป้า (ดาเมจเต็ม) |

**ปฏิสัมพันธ์กับระบบอื่น**
- **ผู้ถือจอก:** ถ้าถูกฆ่าในตะลุมบอน จอกไปที่คนที่ทำดาเมจสุดท้าย ถ้ารอดจนจบ ยังถือจอกต่อ (แม้ไม่ได้กองทรัพยากร)
- **ซ่อนเร้นของ Assassin:** ซุ่มโจมตีได้ในรอบแรก เป้าหมายใช้ทอยป้องกันไม่ได้
- **เงาดำจากจอก:** เป็นผู้เข้าร่วมเพิ่ม 1 ตัว เล็งคนที่ HP สูงสุดทุกรอบ ไม่นับเป็นผู้แข่งเรื่องกองทรัพยากร
- **พันธมิตร:** ไม่มีระบบพันธมิตรทางการ ผู้เล่นตกลงกันในแชตได้ แต่หักหลังได้เสมอ เพราะเลือกเป้าแบบลับ
- **พื้นที่ถนัด/ไม่ถนัด:** มีผลกับทุกลูกเต๋าเหมือนการดวล

**บอทในตะลุมบอน:** เล็งคนที่ฆ่าได้ในรอบนี้ก่อน ไม่งั้นเล็งคนที่ถูกคนอื่นเล็งอยู่แล้ว (ฉวยโอกาส) ใช้ NP วงกว้างเมื่อมีเป้า 3 คนขึ้นไป ป้องกันเมื่อถูกเล็งในรอบก่อนหลายคน

## 8. ความตายและการอัญเชิญใหม่

- Servant HP หมด = **ตาย 1 ครั้ง** นับเข้าตัวนับของแมตช์ (ครบ 7 → จอกปรากฏ)
- จบเฟส Master เลือก **จ่าย Command Seal 1 ดวง** อัญเชิญ Servant ใหม่แบบสุ่มจากกองกลาง (HP เต็ม, ชื่อจริงยังเป็นความลับ)
- **ไม่มี Command Seal เหลือ** → อัญเชิญไม่ได้ Master **ตกรอบ** (ลำดับการตกรอบคืออันดับ)
- Servant ที่ตายแล้วกลับเข้ากองกลางไม่ได้ (กองกลาง 14 ตน พอสำหรับ 8 คน + อัญเชิญใหม่ 6 ครั้ง ⚠️ ถ้าหมดให้สุ่มซ้ำได้)
- การ์ด "วัตถุเชื่อมโยง" ทำให้เลือก Servant เองได้แทนการสุ่ม

## 9. Command Seal (3 ดวง)

ทุกดวงคือทางเลือกระหว่าง "ใช้ตอนนี้" กับ "เก็บไว้เป็นชีวิตสำรอง"

| คำสั่ง | ใช้เมื่อไร | ผล |
|---|---|---|
| **หนี!** | ในการต่อสู้ แทนท่าของรอบ | ออกจากการต่อสู้แน่นอน ย้ายไปพื้นที่ที่เลือก |
| **เพิ่มพลัง!** | ในการต่อสู้ ก่อนทอย | +2 ลูกเต๋าทุกการทอยในรอบนี้ หรือใช้ NP โดยไม่เสียมานา |
| **รักษา!** | เมื่อไรก็ได้ | ฟื้น HP Servant 60% |
| **อัญเชิญ** | หลัง Servant ตาย | อัญเชิญ Servant ใหม่ (บังคับใช้ถ้าจะเล่นต่อ) |

- ได้ Command Seal คืนที่โบสถ์โคโตมิเนะเท่านั้น (สูงสุด 3) ดูข้อ 9.1
- Command Seal ที่เหลือแสดงให้ทุกคนเห็น เพื่อให้ประเมินได้ว่าใครใกล้ตกรอบ ⚠️

ได้การ์ดจากพื้นที่ (ชินโตะ) และจากการชนะต่อสู้ ใช้ได้ทั้งในและนอกการต่อสู้ตามที่ระบุ ⚠️

## 11. จอกศักดิ์สิทธิ์

- ปรากฏเมื่อ **ตายรวมครบ 7 ครั้ง** หรือ **เริ่มวันที่ 8** ประกาศพื้นที่ที่จอกปรากฏ (สุ่ม) ⚠️
- คนแรกที่ไปถึงได้จอก ถ้าไปพร้อมกันหลายคน ต่อสู้ ผู้ชนะได้จอก
- ผู้ถือจอก **ถูกเปิดเผยตำแหน่งทุกเฟส** ใช้ศิลาเขตแดน/ซ่อนเร้นไม่ได้ ได้มานา +3 ทุกเฟส
- ช่วงกลางวันไม่มีการต่อสู้ จอกจึงเปลี่ยนมือได้เฉพาะกลางคืน
- ผู้ถือจอกแพ้การต่อสู้ หรือตกรอบ → จอกตกเป็นของผู้ชนะ
- **เกมจบ** เมื่อจบเฟสกลางคืนวันที่ 8 (ถ้าจอกปรากฏก่อนวันที่ 8 ให้ศึกชิงจอกยาว 4 เฟส ⚠️) หรือเมื่อเหลือ Master คนเดียว
- **ผู้ชนะ** = ผู้ถือจอกตอนเกมจบ ถ้าไม่มีใครถือ ผู้มีมานามากสุดชนะ

## 12. บอท

บอทส่งคำสั่งผ่านช่องทางเดียวกับผู้เล่น ใช้แทนคนที่หลุดได้ทันที

- **พื้นที่:** ให้คะแนน = มานาที่คาดว่าได้ − ความเสี่ยง + โบนัสพื้นที่ถนัด แล้วสุ่มจากคะแนน
- **กลางวัน:** HP < 50% → พักฟื้น · Command Seal ≤ 1 และอยู่โบสถ์ → ธุระโบสถ์ · ไม่รู้ข้อมูลศัตรู → สอดแนม · อื่นๆ → เก็บของ
- **กลางคืน:** ให้คะแนนพื้นที่ = กองทรัพยากรที่คาด − ความแรงของคนที่น่าจะไป (จากที่เห็นตอนกลางวัน) + โบนัสพื้นที่ถนัด · HP ต่ำมากและมีศิลาเขตแดน → ใช้
- **พื้นที่ถนัด:** ไปพื้นที่ถนัดบ่อยกว่าปกติ แต่ไม่ทุกเฟส เพื่อไม่ให้คนเดาออก และหลบพื้นที่ไม่ถนัดตอนต้องสู้
- **อ่านคนอื่น:** จำว่าใครไปพื้นที่ไหนบ่อย เพื่อเดาพื้นที่ถนัดของศัตรู (บอทระดับยาก)
- **ต่อสู้:** ใช้สกิลเมื่อมานาพอ · ใช้ NP เมื่อจบการต่อสู้ได้หรือใกล้แพ้ · หนีเมื่อเสียเปรียบมาก
- **Command Seal:** เก็บไว้อย่างน้อย 1 ดวงเพื่ออัญเชิญเสมอ ยกเว้นช่วงชิงจอก
- **ระดับ:** ง่าย = สุ่มบ่อย · ปกติ = ตามกฎ · ยาก = คำนวณค่าคาดหวังและใช้จุดอ่อนที่รู้

## 13. สถาปัตยกรรมเครือข่าย

```
Browser (Vite)  ⇄  WebSocket  ⇄  Node.js Game Server
ส่งการเลือกพื้นที่/ท่า/การ์ด      ถือสถานะทั้งหมด, จับเวลาเฟส,
แสดงแผนที่ + ลูกเต๋า             ทอยลูกเต๋า, คำนวณผล, รันบอท
```

- **Server ทอยลูกเต๋าเท่านั้น** client แค่แสดงผล
- **ข้อมูลลับไม่ส่งไปที่ client** จนกว่าจะเปิดเผย: ชื่อจริง Servant, พื้นที่ถนัด/ไม่ถนัด, ท่าที่อีกฝ่ายเลือก, พื้นที่ที่เลือกก่อนเปิดเผย, การ์ดในมือ
- คนหลุดแล้วกลับมาได้สถานะล่าสุด ระหว่างหลุดบอทเล่นแทน
- ไลบรารี `ws` ส่ง JSON · โครงสร้าง `client/`, `server/` (room, phase, combat, bot), `shared/` (servants, areas, cards, สูตร)

## 14. แผนพัฒนา
