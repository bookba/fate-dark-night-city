# Fate Battle Royale — เอกสารออกแบบเกม (GDD) v0.1

> สถานะ: ร่างแรก · อ้างอิงโค้ดปัจจุบันใน `game/` (Vite + Canvas 2D, มี `update()/render()` เปล่า)

## 1. ภาพรวม

- **แนวเกม:** Battle Royale มุมมองบนลงล่าง (top-down 2D) ในธีมสงครามจอกศักดิ์สิทธิ์ (Holy Grail War)
- **ผู้เล่น:** 8 คนต่อแมตช์ ช่องที่ว่างเติมด้วยบอทอัตโนมัติ
- **ความยาวแมตช์:** 8–10 นาที
- **เป้าหมาย:** เป็นคู่ Master–Servant คู่สุดท้ายที่รอด เพื่อครอบครองจอกศักดิ์สิทธิ์
- **แพลตฟอร์ม:** เบราว์เซอร์ PC (คีย์บอร์ด + เมาส์) ก่อน มือถือค่อยพิจารณาทีหลัง

## 2. Core Loop

```
เข้าคิว → เลือก Servant → เกิดที่จุดสุ่มในฟุยุกิ
  → สำรวจ / เก็บ "มานา" และไอเท็ม → ปะทะผู้เล่นอื่น
  → เขตแดน (Bounded Field) หดเข้าหาจอก → รอดเป็นคนสุดท้าย = ชนะ
```

วงจรย่อยระหว่างเล่น (30–60 วินาที): หามานา → อัปสกิล/ชาร์จ Noble Phantasm → เลือกจะสู้หรือหนี → ใช้ Command Seal เมื่อคับขัน

## 3. Master & Servant

**ข้อเสนอเริ่มต้น (รอยืนยัน):** ผู้เล่นบังคับ Servant โดยตรง ส่วน Master เป็นตัวละครที่เดินตามหลังอัตโนมัติ

| | Servant | Master |
|---|---|---|
| การควบคุม | ผู้เล่นบังคับ | AI เดินตาม ห่างไม่เกิน ~6 ช่อง |
| HP | สูง | ต่ำ (ประมาณ 1/4 ของ Servant) |
| เมื่อตาย | Servant สลาย (ไม่มีมานาค้ำ) → Master หนีต่อได้ 15 วิ แล้วตกรอบ | **ตกรอบทันที** ทั้งคู่ |

ผลคือมีทางเลือกเชิงกลยุทธ์สองทาง: ตีเข้าหา Servant ตรงๆ หรือหาทางลอบเก็บ Master (แบบ Assassin) นอกจากนี้ Master ยังเป็นแหล่งของ Command Seal

### Command Seal (คาถาบัญชา) — มี 3 ครั้งต่อแมตช์
1. **"มาหาข้า!"** — วาร์ป Servant กลับไปหา Master ทันที
2. **"จงฟื้นคืน!"** — ฟื้น HP Servant 50%
3. **"ปลดปล่อย!"** — ชาร์จ Noble Phantasm เต็มทันที

### Servant คลาส (เริ่มที่ 7 คลาสดั้งเดิม)

| คลาส | บทบาท | จุดเด่น | ตัวอย่าง NP |
|---|---|---|---|
| Saber | ไฟเตอร์รอบด้าน | ดาเมจระยะใกล้สูง, ต้านเวท | ลำแสงเส้นตรงยาว |
| Archer | ยิงระยะไกล | ยิงไกลที่สุด, มองเห็นไกล | ฝนดาบตกเป็นวงกว้าง |
| Lancer | จู่โจมเร็ว | วิ่งเร็ว, พุ่งแทง | แทงนำวิถีโดนแน่ 1 เป้า |
| Rider | เคลื่อนที่ | ขี่พาหนะชนกระเด็น | พุ่งทะลวงระยะไกล |
| Caster | ควบคุมพื้นที่ | วางกับดัก/เขตเวท | ขังศัตรูในพื้นที่ |
| Assassin | ลอบสังหาร | ล่องหน, x2 ดาเมจใส่ Master | ฆ่า Master ทันทีถ้าโดน |
| Berserker | แทงก์ | HP สูงสุด, ฟื้นตัวเอง 1 ครั้ง | คลั่ง เพิ่มพลังโจมตี |

ทุกคลาสมี: โจมตีปกติ (คลิกซ้าย), สกิล 1–2 (Q/E), Noble Phantasm (R, ชาร์จจากการโจมตีและมานา), Dash (Space)

**ความสัมพันธ์คลาส (สามเหลี่ยม):** Saber > Lancer > Archer > Saber (+20% ดาเมจ) · Rider > Caster > Assassin > Rider · Berserker รับ/ทำดาเมจ +20% กับทุกคลาส

## 4. แผนที่: เมืองฟุยุกิ

แผนที่ไทล์ขนาดประมาณ 120×120 ช่อง (ช่องละ 32px) แบ่งเป็นโซน:

| โซน | ลักษณะ |
|---|---|
| วัดริวโด (เหนือ) | ที่สูง บันไดยาว จุดซุ่มยิงดี มานาหนาแน่น |
| ป่าไอนซ์เบิร์น (ตะวันตก) | ต้นไม้บังสายตา เหมาะซุ่ม |
| บ้านเอมิยะ + ย่านมิยามะ | บ้านเรือนแคบ สู้ระยะประชิด |
| สะพานฟุยุกิ (กลาง) | คอขวดเชื่อมสองฝั่งแม่น้ำ |
| ย่านชินโตะ + โบสถ์โคโตมิเนะ (ตะวันออก) | อาคารสูง ถนนกว้าง |
| โรงเรียนโฮมูระฮาระ | อาคารหลายห้อง กับดักเยอะ |

**เขตแดนหด (Bounded Field):** มี 5 ระยะ หดเข้าหา "จุดเกิดจอก" ที่สุ่มเลือกตอนเริ่ม ใครอยู่นอกเขตเสีย HP ต่อวินาทีเพิ่มขึ้นทุกระยะ

**ของในแผนที่:** ผลึกมานา (XP), ยาฟื้น HP, เศษ Command Seal (หายากมาก คืน 1 ครั้ง), เส้นเลย์ไลน์ (ยืนบนนี้ชาร์จ NP เร็วขึ้น)

## 5. ลำดับแมตช์

| ช่วง | เวลา | สิ่งที่เกิด |
|---|---|---|
| Lobby | ≤ 30 วิ | รอผู้เล่น ครบ 8 หรือหมดเวลา → เติมบอท |
| Summoning | 15 วิ | เลือก Servant (ห้ามซ้ำคลาสเกิน 2) |
| Deploy | — | เกิดกระจายรอบแผนที่ ป้องกันการเกิดใกล้กัน |
| ระยะ 1–5 | ~8 นาที | เขตแดนหดทุก ~90 วิ |
| End | — | ประกาศผู้ชนะ, สรุปคิล/ดาเมจ, กลับ Lobby |

ผู้เล่นที่ตกรอบดูต่อแบบ spectator ได้ และกด "เล่นใหม่" ได้ทันที

## 6. บอท

บอทใช้โค้ดเดียวกับผู้เล่น ต่างตรงที่ input มาจาก AI แทนคีย์บอร์ด (ส่ง "คำสั่ง" เดียวกันเข้า server) จึงสลับคนออกกลางเกมแล้วให้บอทเล่นแทนได้

**State machine:**
- **Roam** — เดินไปหามานา/ไอเท็มที่ใกล้ที่สุด ภายในเขตแดน
- **Engage** — เจอศัตรูในระยะมองเห็น และ HP ตัวเอง > 40% → เข้าโจมตี เลือกสกิลตามระยะ
- **Flee** — HP < 30% → หนีห่างศัตรู ใช้ Command Seal ฟื้น HP ถ้ายังมี
- **Rotate** — ใกล้ขอบเขตแดน → เดินเข้าศูนย์กลาง
- **Hunt Master** — (Assassin/บอทระดับยาก) อ้อมไปเก็บ Master ฝ่ายตรงข้าม

**ระดับความยาก:** ปรับเวลาตอบสนอง (150–600ms), ความแม่นการเล็ง, และการใช้ NP · ค่าเริ่มต้นจับความยากตามจำนวนผู้เล่นจริงในห้อง

การเดินหาทางใช้ A* บนตารางไทล์ (คำนวณใหม่ทุก ~0.5 วิ ไม่ต้องทุกเฟรม)

## 7. สถาปัตยกรรมเครือข่าย

```
Browser (Vite + Canvas)  ⇄  WebSocket  ⇄  Node.js Game Server (authoritative)
    ส่ง input อย่างเดียว              จำลองเกม 20 tick/วิ, AI บอท, ตรวจโกง
    render + interpolation           ส่ง snapshot สถานะ 20 ครั้ง/วิ
```

- **Server เป็นผู้ตัดสิน (authoritative):** client ส่งแค่ input (ทิศเดิน, ทิศเล็ง, ปุ่มที่กด, เลข sequence) server คำนวณชน/ดาเมจทั้งหมด → กันโกงพื้นฐาน
- **Tick rate:** จำลอง 20 Hz (50ms) เพียงพอสำหรับเกม top-down 8 คน
- **ฝั่ง client:** ทำนายการเดินของตัวเองทันที (client-side prediction) แล้วปรับตาม server (reconciliation) ส่วนผู้เล่นอื่นแสดงแบบ interpolation ย้อนหลัง ~100ms ให้ภาพลื่น
- **ไลบรารี:** `ws` ฝั่ง server ไม่ต้องใช้ framework ใหญ่ ส่ง JSON ก่อน ค่อยเปลี่ยนเป็น binary เมื่อจำเป็น
- **ห้อง:** server หนึ่งตัวรันได้หลายห้อง แต่ละห้องเป็น object แยก มี matchmaking แบบง่าย (เข้าห้องแรกที่ยังไม่เต็ม)
- **โค้ดร่วม:** กติกาเกม (ฟิสิกส์, สกิล, ค่าสถานะ) อยู่ในโฟลเดอร์ `shared/` ใช้ทั้ง client และ server

### โครงสร้างโปรเจกต์ที่เสนอ

```
game/
  client/      ← ของเดิม (index.html, src/main.js) ย้ายมาที่นี่
    src/ render/ input/ net/ ui/
  server/      ← Node.js: index.js, room.js, bot.js
  shared/      ← constants.js, servants.js, simulation.js, map.js
```

รันบน Windows ระหว่างพัฒนา: `npm run dev` เปิดทั้ง Vite (client) และ server พร้อมกัน ทดสอบหลายผู้เล่นได้ด้วยการเปิดหลายแท็บ

### การขึ้นออนไลน์จริง (ภายหลัง)
Client เป็นไฟล์ static วางบน host ฟรีได้ (เช่น Netlify/Vercel) ส่วน game server ต้องการเครื่องที่รัน Node ได้ตลอด (เช่น Render, Fly.io หรือ VPS)

## 8. แผนการพัฒนา (Milestones)

1. **M1 — เล่นคนเดียวกับบอท (ออฟไลน์):** แผนที่, Servant 1 คลาส (Saber), เดิน/โจมตี, บอท 7 ตัว, เขตแดนหด
2. **M2 — ออนไลน์:** แยก server, WebSocket, หลายแท็บเล่นด้วยกันได้, บอทเติมช่องว่าง
3. **M3 — ครบระบบ Master/Servant:** Master, Command Seal, Noble Phantasm
4. **M4 — คลาสครบ 7:** สมดุลเกม, ความสัมพันธ์คลาส
5. **M5 — ขัดเกลา:** ภาพ/เสียง, UI Lobby, spectator, deploy ขึ้นเน็ต

M1 จงใจทำให้ simulation อยู่ใน `shared/` ตั้งแต่แรก เพื่อให้ M2 แค่ย้ายมันไปรันบน server

## 9. ข้อสังเกต: ลิขสิทธิ์

Fate/stay night เป็นของ TYPE-MOON ถ้าเล่นกันเองหรือเป็นแฟนเกมไม่หวังกำไรมักไม่มีปัญหา แต่ถ้าจะเผยแพร่วงกว้างหรือหารายได้ ควรใช้ชื่อคลาส/ตัวละครที่ออกแบบเอง (ระบบคลาสแบบ Saber/Archer ใช้ได้ แต่หลีกเลี่ยงชื่อตัวละครและภาพจากเกมต้นฉบับ)
