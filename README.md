# Fate Battle Royale

เว็บเกม Battle Royale ธีม Fate/stay night (Vite + JavaScript)

ตอนนี้เป็นเดโมออฟไลน์ตามกติกา v1.1 ในเอกสารออกแบบ: ผู้เล่น 1 คนปะทะบอท 7 ตัวในเบราว์เซอร์ 8 วัน (กลางวันเลือกพื้นที่ · กลางคืนย้ายแล้วลงการ์ดสู้)

## รัน

```
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

เอกสารออกแบบเกม: [docs/game-design.md](docs/game-design.md)

## โครงสร้างโค้ด

- `src/data.js` — 4 พื้นที่ เด็ค Servant 14 ตน (ตนละ 13 ใบ) การ์ดสถานการณ์ อีเวนต์ ไอเท็ม และเควสโบสถ์
- `src/engine.js` — กติกาทั้งหมด (เลือกพื้นที่พร้อมกัน ความจุพื้นที่ ย้าย/หนี ลงการ์ด+ลูกเต๋า ธงยึดครอง Command Seal จอก) ไม่มีโค้ด DOM จึงย้ายไปรันบน server ได้ภายหลัง
- `src/bot.js` — บอทระดับปกติ ตอบผ่านช่องทางเดียวกับผู้เล่น
- `src/ui.js`, `src/style.css` — หน้าจอ HUD (เลือกพื้นที่ ย้าย ลงการ์ด) และฉากต่อสู้แบบมีแอนิเมชัน
- `src/portraits.js` — รูปประจำคลาสชั่วคราว (SVG) เปลี่ยนเป็นรูปจริงได้ที่ `CLASS_ART`
- `npm run sim` — จำลองเกมบอทล้วน 200 เกม แล้วพิมพ์ค่าเฉลี่ยไว้ปรับบาลานซ์
