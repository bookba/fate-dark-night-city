# Fate Battle Royale

เว็บเกม Battle Royale ธีม Fate/stay night (Vite + JavaScript)

ตอนนี้เป็นเดโมออฟไลน์ตามกติกา v1.8 ในเอกสารออกแบบ: ผู้เล่น 1 คนปะทะบอท 7 ตัวในเบราว์เซอร์ 8 วัน (กลางวันเลือกพื้นที่ · กลางคืนย้ายแล้วลงการ์ดสู้)

## รัน

```
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

เอกสารออกแบบเกม: [docs/game-design.md](docs/game-design.md)

## โครงสร้างโค้ด

- `src/data.js` — 5 พื้นที่ สำรับ Servant 14 ตน + Alter 14 ตน (ตนละ 12 ใบ NP เป็นความสามารถ) อีเวนต์ประจำวัน 17 ใบ การ์ดรางวัล ไอเท็ม และธุระโบสถ์ (ถวายมานา / ปราบมอนสเตอร์)
- `src/engine.js` — กติกาทั้งหมด (เลือกพื้นที่พร้อมกัน ความจุพื้นที่ ย้าย/หนี ลงการ์ด+ลูกเต๋า ธงยึดครอง Command Seal จอก) ไม่มีโค้ด DOM จึงย้ายไปรันบน server ได้ภายหลัง
- `src/bot.js` — บอทระดับปกติ ตอบผ่านช่องทางเดียวกับผู้เล่น
- `src/ui.js`, `src/style.css` — หน้าจอ HUD (เลือกพื้นที่ ย้าย ลงการ์ด) และฉากต่อสู้แบบมีแอนิเมชัน
- `src/help.js` — ข้อความอธิบายในเกม (ภาคผนวก ก): คำอธิบายใต้ปุ่ม คำศัพท์ คำแนะนำวันแรก และคู่มือปุ่ม "?"
- `src/portraits.js` — รูปประจำคลาสชั่วคราว (SVG) เปลี่ยนเป็นรูปจริงได้ที่ `CLASS_ART`
- `npm run sim` — จำลองเกมบอทล้วน 200 เกม แล้วพิมพ์ค่าเฉลี่ยไว้ปรับบาลานซ์

## เดโม v5 (Dominate Grail War ตามคู่มือทางการ)

เดโมตามกระดาษออกแบบ v5.0 อยู่ในโฟลเดอร์ `v5/` แยกจากของเดิม: กฎตามคู่มือบอร์ดเกม Dominate Grail War ด่านเดียว (เมืองฟุยุกิ) Master 7 คนกับ Servant 7 ตน ผู้เล่น 1 คนกับบอท 6 ตัว เล่น 8 รอบแล้วเข้าไคลแมกซ์ คัดออกเหลือ 4 → 2 → 1 (เสมอที่เส้นตัดออกทุกคน) Command Spell ใช้ในตาปฏิบัติการของตัวเอง ลงการ์ดคว่ำได้ทั้ง 2 ใบ ความสามารถ Master ตามคู่มือ (Avalon ของชิโร่ ชินจิชนะพิเศษ ฯลฯ)

หน้าจอพอดีจอเสมอ (หน้าเว็บไม่เลื่อน): แถบบอกว่าตาใคร กระดานเต็มพื้นที่ที่เหลือ แตะพื้นที่แล้วขึ้นป๊อปอัปให้ดูรายละเอียดและทำแอคชั่น (ป๊อปอัปอัปเดตในหน้าต่างเดิม และพับเป็นแถบเล็กได้ด้วยปุ่ม ▾) ตัวนับต่างๆ แสดงแค่ค่าปัจจุบัน บนจอกว้าง 1100px ขึ้นไปมีคอลัมน์ข้าง (Master ของคุณ อันดับ บันทึก) จอที่เล็กกว่านั้นเปิดจากปุ่มด้านล่าง แผนที่เลือกรูปเองตามขนาดกระดาน (แถวเดียวหรือรูปตะขอ) และแต่ละพื้นที่ซ่อนข้อความที่ไม่พอที่จะใส่

```
npx vite v5
```

- `v5/data.js` — Master Servant การ์ดสถานการณ์ การ์ดอีเวนต์ ตัวเลขส่วนใหญ่เป็น **ค่าแทน** (รายการอยู่ใน `design/v5-card-placeholders.md` ของโปรเจกต์)
- `v5/game.js` — กติกาทั้งหมด ไม่มีโค้ด DOM
- `v5/bot.js` — บอท ตอบผ่านช่องทางเดียวกับผู้เล่น
- `v5/main.js`, `v5/style.css`, `v5/index.html` — หน้าจอ: แถบสถานะ กระดาน ป๊อปอัปของแต่ละพื้นที่และการลงการ์ด คอลัมน์ข้างหรือปุ่มด้านล่าง
- `node v5/sim.mjs 300` — ให้บอทเล่นล้วนแล้วเช็กว่ามานา การ์ด และการคัดออกไม่ผิดพลาด

## เดโม v4 (Fate/Domination, 1 ด่าน)

เดโมตามกระดาษออกแบบ v4.1 อยู่ในโฟลเดอร์ `v4/` แยกจากของเดิม: ด่านเดียว (เมืองฟุยุกิ) Master 7 คนกับ Servant 7 ตนของ Fate/stay night ผู้เล่น 1 คนกับบอท 6 ตัว 11 รอบ (ปกติ 8 + ไคลแมกซ์ 3) คัดออกเหลือ 4, 3, 2 คนหลังรอบ 8, 9, 10

v4.1 เพิ่มช่วงใช้ความสามารถทุกขั้น (เตรียมการ ตั้งมั่น ปฏิบัติการ ต่อสู้) ตามต้นฉบับ: Command Spell ใช้ได้ทุกช่วง มีหน้าใช้ความสามารถก่อนตัดสินผลต่อสู้ อัญมณีของรินใช้ลงการ์ด Gand และแลกการ์ดในมือได้ และ Kanshou & Bakuya ใช้ในรอบที่ห้าม NP ไม่ได้

```
npx vite v4
```

- `v4/data.js` — Master Servant อีเวนต์ ออบเจกต์ ตัวเลขส่วนใหญ่เป็น **ค่าแทน** (รายการอยู่ใน `design/v4-card-placeholders.md` ของโปรเจกต์)
- `v4/game.js` — กติกาทั้งหมด ไม่มีโค้ด DOM
- `v4/bot.js` — บอท ตอบผ่านช่องทางเดียวกับผู้เล่น
- `v4/main.js`, `v4/style.css`, `v4/index.html` — หน้าจอใหม่: กระดานที่กดเลือกได้ แผงตัดสินใจทีละขั้น ตัวอย่างพลังก่อนลงการ์ด ตารางอันดับพร้อมเส้นตัด และหน้าผลการต่อสู้
- `node v4/sim.mjs 300` — ให้บอทเล่นล้วนแล้วเช็กว่ามานา Command Spell VP การ์ด และการคัดออกไม่ผิดพลาด

## เดโม v3 (Fate/Dominate Grail War)

เดโมตามกระดาษออกแบบ v3.0 อยู่ในโฟลเดอร์ `v3/` แยกจากของเดิม (`src/` คือ v1.8, `v2/` คือ v2.0): ผู้เล่น 1 คนกับบอท 6 ตัว เล่น 8 รอบแล้วเข้าไคลแมกซ์ มีโหมดแบบสั้น 4 รอบ

```
npx vite v3
```

- `v3/data.js` — Master 7 คน Servant 9 ตน การ์ดอีเวนต์ 20 ใบ การ์ดสถานการณ์ ตัวเลขการ์ดเกือบทั้งหมดเป็น **ค่าแทน** เพราะไม่มีแหล่งไหนเปิดเผยของจริง (ค่าที่รู้มีป้ายแหล่งข้อมูลกำกับ)
- `v3/game.js` — กติกาทั้งหมด ไม่มีโค้ด DOM
- `v3/bot.js` — บอท ตอบผ่านช่องทางเดียวกับผู้เล่น
- `v3/main.js`, `v3/style.css` — หน้าจอ: วางหมาก ย้าย ลงการ์ด และหน้าผลต่อสู้
- `node v3/sim.mjs 300 full` (หรือ `casual`) — ให้บอทเล่นล้วนแล้วเช็กว่ามานา Command Spell และการ์ดไม่ผิดพลาด
