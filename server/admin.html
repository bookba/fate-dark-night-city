แก้ทุกอย่างบนหน้าเกมจริง

เปิดเกมในโหมดแก้ไข แล้วกด "✏️ แก้ไข" ที่แถบด้านล่าง แตะข้อความไหนก็ได้เพื่อเปลี่ยนข้อความ แตะรูปไหนก็ได้เพื่อเปลี่ยนรูป ระหว่างเปิดโหมดแก้ไข การแตะจะไม่ไปกดปุ่มในเกม ปิดโหมดแก้ไขเพื่อเล่นไปยังหน้าที่ต้องการแก้ (เช่น ป๊อปอัปการ์ด) แล้วเปิดใหม่

ผู้เล่นเห็นเมื่อไร

ทุกการแก้ไขบันทึกบนเซิร์ฟเวอร์ทันที ผู้เล่นทุกคนเห็นเมื่อเปิดหรือรีเฟรชหน้าเกม (เกมที่เล่นค้างอยู่ไม่สะดุด) ลิงก์หน้านี้มีรหัสอยู่ อย่าส่งต่อ

รูปทั้งหมดในเว็บ กด "เปลี่ยน" แล้วเลือกไฟล์ รูปใหม่ขึ้นแทนรูปเดิมทุกที่ในเกม (webp png jpg gif svg ไม่เกิน 8 MB) ไอคอนและตราคลาสที่วาดด้วยโค้ดเปลี่ยนสีได้ในแท็บ "สี / CSS"

เสียงในเกมสร้างด้วยโค้ด ใส่ไฟล์เสียงแทนได้ทีละเสียง (mp3 wav ogg m4a webm ไม่เกิน 8 MB) ดังตามระดับเสียงที่ผู้เล่นตั้งไว้

ข้อความทุกข้อความของเกม เลือกภาษาแล้วแก้ในช่องขวา ปล่อยว่างเท่ากับใช้ข้อความเดิม {0} {1} คือที่ที่เกมใส่ชื่อหรือตัวเลข ต้องเก็บไว้ บันทึกเองเมื่อออกจากช่อง

ยังไม่มีระบบหลายภาษาในเซิร์ฟเวอร์นี้ ใช้ "แก้บนหน้าเกม" ไปก่อน
ข้อความต้นฉบับ (ไทย) / ข้อความเดิมของภาษานี้ข้อความใหม่

ข้อความที่แก้ด้วยการแตะบนหน้าเกม เปลี่ยนเมื่อข้อความบนหน้าจอตรงกับช่องซ้ายทั้งก้อน แยกตามภาษา เพิ่มเองได้ที่แถวล่างสุด

ข้อความบนหน้าจอเปลี่ยนเป็น

CSS เพิ่มเติม ใส่ท้ายหน้าเกม ใช้เปลี่ยนสี ตัวอักษร ขนาด ซ่อนสิ่งที่ไม่ต้องการ ฯลฯ ตัวอย่าง: :root { --gold: #c00; } หรือ body { font-size: 18px; }
