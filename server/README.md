# เซิร์ฟเวอร์เล่นออนไลน์ (เดโม v5)

เซิร์ฟเวอร์นี้รันเกมจริงเพียงเกมเดียวต่อห้อง (`v5/game.js` ตัวเดิม ไม่แก้กติกา) แล้วส่งให้แต่ละหน้าเห็นเฉพาะสิ่งที่ Master คนนั้นควรเห็น

- ห้องละไม่เกิน 7 คน คนละ 1 Master ที่นั่งที่ไม่มีคนเล่นเป็นบอท
- สร้างห้องแล้วได้รหัส 4 ตัว ส่งรหัสหรือลิงก์ `?room=รหัส` ให้เพื่อน
- เวลาคิด 30 วินาทีทุกคำถาม (กระดาษข้อ 4.6 ข้อ 21) หัวห้องปิดได้ในห้อง หมดเวลาแล้วเกมเลือกแบบปลอดภัยตามข้อ 21 และบันทึกสงครามเขียน "หมดเวลา"
- ผลการต่อสู้เปิดให้ดูได้ 15 วินาที หรือจนทุกคนกด "จบรอบ" แล้วเกมเดินต่อ
- ใครหลุด บอทเล่นแทนจนกว่าจะกลับมา เปิดลิงก์ห้องเดิมในเครื่องเดิมแล้วได้ที่นั่งเดิมคืน
- มือ สำรับ การ์ดคว่ำ และ Servant ที่ยังไม่เปิดชื่อจริงของคนอื่นไม่ถูกส่งไปที่หน้าเว็บเลย จึงแอบดูจากเครื่องตัวเองไม่ได้
- ไม่ต้องติดตั้งแพ็กเกจ ใช้ Node.js 20 ขึ้นไปอย่างเดียว

## ลองบนเครื่องตัวเอง

```
node server/index.mjs
```

แล้วเปิด http://localhost:8080/ กด "🌐 เล่นออนไลน์" ลองเปิดอีกหน้าต่างหนึ่ง (หรือโทรศัพท์ในวง Wi-Fi เดียวกัน ที่ `http://<IP เครื่อง>:8080/`) แล้วเข้าห้องด้วยรหัสเดียวกัน

ทดสอบอัตโนมัติ (ผู้เล่นจำลอง 3 คนเล่นจนจบเกม ตรวจว่าไม่เห็นมือคนอื่น): `npm run online:test`

## เอาขึ้นเว็บ (Render แบบฟรี)

1. สมัคร https://render.com ด้วยบัญชี GitHub
2. กด **New +** → **Blueprint** → เลือก repo `bookba/fate-dark-night-city` และ branch ที่มีไฟล์ `render.yaml` (branch ที่รวมทุกอย่างล่าสุด: ออนไลน์ + ภาษา + แอดมิน + สมาชิก คือ `claude/project-thread-vs1bcx` ถ้ารวมเข้า main แล้วเลือก `main`)
3. กด **Apply** รอสร้างเสร็จ (ไม่กี่นาที) จะได้ลิงก์แบบ `https://fdnc.onrender.com` (ชื่อมาจาก `name:` ใน `render.yaml` ถ้ามีคนใช้ชื่อนี้แล้ว Render จะต่อท้ายด้วยตัวอักษรสุ่ม)
4. เปิดลิงก์นั้น กด "🌐 เล่นออนไลน์"

### เปลี่ยนชื่อลิงก์ .onrender.com

Render เปลี่ยนชื่อลิงก์ของบริการที่สร้างแล้วไม่ได้ ให้แก้ `name:` ใน `render.yaml` แล้วลบบริการเดิม (Settings → Delete Web Service) และทำขั้นที่ 2–3 ใหม่ ลิงก์เดิมจะใช้ไม่ได้อีก ห้องที่ค้างอยู่จะหาย

แบบฟรีของ Render หลับเมื่อไม่มีคนเข้า 15 นาที คนแรกที่เปิดจะรอให้ตื่นราวหนึ่งนาที และห้องที่เล่นค้างอยู่จะหายเมื่อเซิร์ฟเวอร์หลับหรือรีสตาร์ต

## หน้าแอดมิน (แก้รูป ข้อความ เสียง CSS ของทั้งเว็บ)

เข้าทางลิงก์ลับ: `https://fdnc.onrender.com/admin?key=รหัสแอดมิน` รหัสผิดหรือไม่ใส่จะขึ้น "not found" เหมือนไม่มีหน้านี้ ใส่ผิด 8 ครั้งใน 15 นาที ที่อยู่นั้นถูกปิด 15 นาที เซิร์ฟเวอร์ตรวจรหัสทุกครั้งที่บันทึก

ตั้งค่าบน Render (Dashboard → บริการ fdnc → **Environment** → Add Environment Variable แล้ว Save):

1. `ADMIN_KEY` = รหัสแอดมินที่ตั้งเอง (ยาว 12 ตัวขึ้นไป อย่าใส่ใน repo) ไม่ตั้ง = ปิดหน้าแอดมิน
2. `GITHUB_TOKEN` = โทเคน GitHub ให้เก็บการแก้ไขถาวร (Render แบบฟรีลบดิสก์ทุกครั้งที่เซิร์ฟเวอร์หลับหรือรีสตาร์ต ถ้าไม่ตั้ง การแก้ไขจะหายภายในไม่กี่ชั่วโมง)
   - สร้างที่ GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: Only select repositories → `bookba/fate-dark-night-city`
   - Permissions → Repository permissions → **Contents: Read and write**
   - การแก้ไขถูกเก็บใน branch `admin-data` โฟลเดอร์ `admin-data/` (ไม่แตะ branch ของเกม)
3. `GITHUB_REPO` = `bookba/fate-dark-night-city` และ `GITHUB_BRANCH` = `admin-data` (มีใน `render.yaml` แล้ว)

ในหน้าแอดมิน (แถบข้างแบ่งเป็นหมวด):

- **ภาพรวม**: จำนวนสิ่งที่แก้ไว้ในแต่ละหมวด สถานะที่เก็บ และปุ่มเปิดเกมในโหมดแก้ไข (กด "✏️ แก้ไข" แล้วแตะข้อความหรือรูปไหนก็ได้)
- **เนื้อหาเกม**
  - **Servant และการ์ด**: การ์ด Servant ทั้ง 9 ตน กดเข้าไปแก้ชื่อที่แสดง รูป Servant ไอคอน คำอธิบาย การ์ด NP / สกิลทุกใบ (พลัง มานา ข้อความแยกภาษา รูปการ์ดถ้ามี) และพลังของการ์ดพื้นฐานในสำรับ (มานา = พลัง − 3) ตัวเลขใช้ทั้งเกมกับบอทและเกมออนไลน์ เกมที่เริ่มหลังบันทึกใช้ค่าใหม่ (`applyGameEdits` ใน `v5/data.js`)
  - **ข้อความทุกภาษา**: ทุกข้อความในพจนานุกรมภาษา (`v5/i18n.js`) ไทย อังกฤษ จีน ญี่ปุ่น
  - **ข้อความบนหน้าเกม**: ข้อความที่แก้ด้วยการแตะบนหน้าเกม
- **หน้าตา**
  - **ฉากหลังและสี**: ฉากหลังหน้าเกม กระดาน หน้าต่างใหญ่ ป๊อปอัป และแผงข้าง เป็นสี ไล่สี หรือรูป (รูปในเกมหรืออัปโหลดเอง ปรับความมืด การวางรูป) หลังการ์ด และสีหลักของเกม มีภาพตัวอย่างก่อนกดบันทึก (`themeCss` ใน `v5/custom.js`)
  - **รูปภาพ**: รูปทั้งหมดในเว็บ แยกหมวด (Servant ไอคอน การ์ด แผนที่ ส่วนประกอบหน้าจอ) เปลี่ยน/คืนรูปเดิม
  - **CSS เพิ่มเติม**: สำหรับปรับละเอียด
- **เสียง**: ใส่ไฟล์เสียงแทนเสียงแต่ละแบบในเกม ฟังเทียบเสียงเดิมกับเสียงใหม่ได้
- **ผู้เล่น**: สมาชิก
- **ระบบ**: สถานะที่เก็บ ดาวน์โหลดไฟล์สำรอง (มีทุกอย่างรวมรูปฉากหลังที่อัปโหลด) นำกลับมา คืนค่าเดิมทั้งเว็บ

ผู้เล่นเห็นการแก้ไขเมื่อเปิดหรือรีเฟรชหน้าเกม เดโมใน Claude artifact ไม่มีเซิร์ฟเวอร์ จึงเป็นแบบเดิมเสมอ

ลองบนเครื่อง: `ADMIN_KEY=test node server/index.mjs` แล้วเปิด http://localhost:8080/admin?key=test (Windows PowerShell: `$env:ADMIN_KEY="test"; node server/index.mjs`)

## สมาชิก โปรไฟล์ ล็อบบี้ ห้อง

กด "🌐 เล่นออนไลน์" แล้วจะเห็นล็อบบี้:

- **สมัครสมาชิก / เข้าสู่ระบบ** ด้วยชื่อผู้ใช้ (ตัวอังกฤษ ตัวเลข _ 3–16 ตัว) กับรหัสผ่าน ไม่ต้องใช้อีเมล หรือเล่นแบบไม่สมัครก็ได้เหมือนเดิม เครื่องจำการเข้าสู่ระบบไว้ 60 วัน
- **โปรไฟล์**: ชื่อที่แสดง รูป (Servant หรือสีของ Master) แนะนำตัว สถิติ (เกม ชนะ อัตราชนะ ติด 3 อันดับแรก VP สูงสุด/เฉลี่ย Master ที่เล่นบ่อย) และประวัติ 30 เกมล่าสุด กดชื่อใครก็ได้ในห้อง แชต หรืออันดับเพื่อดูโปรไฟล์ เปลี่ยนรหัสผ่านได้ในโปรไฟล์
- **ห้อง**: รายชื่อห้องที่เปิดอยู่ (อัปเดตเอง) กดเข้าได้เลย · ⚡ เข้าห้องด่วน · สร้างห้องพร้อมชื่อห้อง เลือกให้แสดงในรายชื่อหรือไม่ (ไม่แสดง = เข้าได้ด้วยรหัส/ลิงก์เท่านั้น) · หัวห้องเปลี่ยนชื่อห้องและเชิญคนออกได้ก่อนเริ่มเกม
- สมาชิกที่หลุดหรือเปลี่ยนเครื่อง เข้าสู่ระบบแล้วได้ที่นั่งเดิมคืน (ล็อบบี้ขึ้นปุ่ม "กลับเข้าห้อง")
- **แชต**: แชตล็อบบี้ (เฉพาะสมาชิก) และแชตในห้อง (ทุกคน) ระหว่างเกมกด 💬 ที่แถบบน มีเลขบอกข้อความใหม่ จำกัด 1 ข้อความต่อวินาที
- **เพื่อน**: เพิ่มด้วยชื่อผู้ใช้หรือจากโปรไฟล์ อีกฝ่ายกดรับ เห็นว่าเพื่อนออนไลน์ไหม อยู่ห้องไหน (กดไปห้องนั้นได้) และเชิญเพื่อนเข้าห้อง (ขึ้นแจ้งเตือนพร้อมปุ่มเข้าห้อง)
- **อันดับ**: สมาชิกที่ชนะมากที่สุด 50 คน (นับเฉพาะเกมออนไลน์ที่เล่นจบ)
- **หน้าแอดมิน → แท็บ "สมาชิก"**: ค้นหาสมาชิก เปลี่ยนชื่อ ตั้งรหัสผ่านใหม่ให้คนที่ลืม (ขึ้นรหัสใหม่ครั้งเดียว) ระงับ/เลิกระงับ ลบบัญชี และดูเกมล่าสุด

### ที่เก็บข้อมูลสมาชิก (ต้องตั้งบน Render)

Render แบบฟรีลบดิสก์ทุกครั้งที่หลับ ข้อมูลสมาชิกจึงเก็บใน GitHub แบบเดียวกับหน้าแอดมิน: branch `admin-data` ไฟล์ `admin-data/accounts.bin` **เข้ารหัส** (AES-256-GCM) เพราะ repo เป็นสาธารณะ รหัสผ่านเก็บเป็นค่าแฮช scrypt เท่านั้น

1. `GITHUB_TOKEN` ตัวเดียวกับหน้าแอดมิน (ข้างบน) ต้องตั้งแล้ว ไม่อย่างนั้นบัญชีหายเมื่อเซิร์ฟเวอร์หลับ
2. `ACCOUNTS_KEY` = กุญแจเข้ารหัสข้อมูลสมาชิก `render.yaml` ให้ Render สุ่มให้เอง (Blueprint → Sync) ถ้าสร้างบริการเองโดยไม่ใช้ Blueprint ให้เพิ่มเอง เป็นตัวอักษรสุ่มยาว 32 ตัวขึ้นไป **ตั้งแล้วห้ามเปลี่ยน** เปลี่ยนแล้วเปิดข้อมูลเดิมไม่ได้ (ถ้าไม่ตั้ง ใช้กุญแจที่ทำจาก `GITHUB_TOKEN` แทน ซึ่งจะเปิดไม่ได้เมื่อเปลี่ยนโทเคน)

บันทึกลง GitHub ภายใน 10–60 วินาทีหลังมีการเปลี่ยน และทันทีเมื่อ Render สั่งปิดเซิร์ฟเวอร์ แชตไม่ถูกเก็บ (หายเมื่อเซิร์ฟเวอร์หลับ)

ทดสอบอัตโนมัติ (สมัคร เข้าสู่ระบบ เพื่อน เชิญ แชต รายชื่อห้อง เตะ ย้ายเครื่อง รีสตาร์ต): `npm run online:test-social`

## ไฟล์

- `server/index.mjs` เว็บเซิร์ฟเวอร์ (ส่งหน้า `v5/` และรูปการ์ด) และ WebSocket ที่ `/ws`
- `server/hub.mjs` การเชื่อมต่อของแต่ละหน้า: เข้าสู่ระบบ รายชื่อห้อง แชต เพื่อน คำเชิญ แล้วส่งต่อให้ห้อง
- `server/accounts.mjs` สมาชิก รหัสผ่าน โปรไฟล์ เพื่อน ประวัติการเล่น อันดับ ที่เก็บ (ดิสก์ + GitHub เข้ารหัส) และแท็บสมาชิกของหน้าแอดมิน
- `server/room.mjs` ห้อง ที่นั่ง ใครตอบคำถามไหน เวลาคิด และคำตอบตอนหมดเวลา
- `server/ws.mjs` WebSocket ขนาดเล็กที่เขียนเอง
- `v5/net.js` วิธีส่งเกมไปหน้าเว็บ และสิ่งที่แต่ละคนห้ามเห็น (ใช้ทั้งเซิร์ฟเวอร์และหน้าเว็บ)
- `v5/online.js` หน้าเว็บฝั่งออนไลน์: ล็อบบี้ (ห้อง แชต เพื่อน อันดับ) สมัคร/เข้าสู่ระบบ โปรไฟล์ ห้อง แชตระหว่างเกม ป้ายห้อง นาฬิกาเวลาคิด
- `server/admin.mjs` หน้าแอดมิน: ตรวจรหัส เก็บการแก้ไข (ดิสก์ + GitHub) ส่งรูป/ข้อความ/เสียงที่แก้ให้ผู้เล่น
- `server/admin.html` หน้าแอดมิน
- `v5/custom.js` หน้าเกมรับการแก้ไข (ข้อความบนหน้าจอ CSS) · `v5/admin-edit.js` โหมดแก้บนหน้าเกม
