# เซิร์ฟเวอร์เล่นออนไลน์ (เดโม v5)

เซิร์ฟเวอร์นี้รันเกมจริงเพียงเกมเดียวต่อห้อง (`v5/game.js` ตัวเดิม ไม่แก้กติกา) แล้วส่งให้แต่ละหน้าเห็นเฉพาะสิ่งที่ Master คนนั้นควรเห็น

- ห้องละไม่เกิน 7 คน คนละ 1 Master ที่นั่งที่ไม่มีคนเล่นเป็นบอท
- สร้างห้องแล้วได้รหัส 4 ตัว ส่งรหัสหรือลิงก์ `?room=รหัส` ให้เพื่อน
- เวลาคิด 30 วินาทีทุกคำถาม (กระดาษข้อ 4.6 ข้อ 21) หัวห้องปิดได้ในห้อง หมดเวลาแล้วเกมเลือกแบบปลอดภัยตามข้อ 21 และบันทึกสงครามเขียน "หมดเวลา"
- ผลการต่อสู้เปิดให้ดูได้ 15 วินาที หรือจนทุกคนกด "จบรอบ" แล้วเกมเดินต่อ
- ใครหลุด บอทเล่นแทนจนกว่าจะกลับมา เปิดลิงก์ห้องเดิมในเครื่องเดิมแล้วได้ที่นั่งเดิมคืน
- มือ สำรับ การ์ดคว่ำ และ Servant ที่ยังไม่เปิดชื่อจริงของคนอื่นไม่ถูกส่งไปที่หน้าเว็บเลย จึงแอบดูจากเครื่องตัวเองไม่ได้
- ไม่ต้องติดตั้งแพ็กเกจ ใช้ Node.js 20 ขึ้นไปอย่างเดียว

## ลองบนเครื่องตัวเอง

```
node server/index.mjs
```

แล้วเปิด http://localhost:8080/ กด "🌐 เล่นออนไลน์" ลองเปิดอีกหน้าต่างหนึ่ง (หรือโทรศัพท์ในวง Wi-Fi เดียวกัน ที่ `http://<IP เครื่อง>:8080/`) แล้วเข้าห้องด้วยรหัสเดียวกัน

ทดสอบอัตโนมัติ (ผู้เล่นจำลอง 3 คนเล่นจนจบเกม ตรวจว่าไม่เห็นมือคนอื่น): `npm run online:test`

## เอาขึ้นเว็บ (Render แบบฟรี)

1. สมัคร https://render.com ด้วยบัญชี GitHub
2. กด **New +** → **Blueprint** → เลือก repo `bookba/fate-dark-night-city` และ branch ที่มีไฟล์ `render.yaml` (ตอนนี้คือ `claude/project-thread-4hfhf2` ถ้ารวมเข้า main แล้วเลือก `main`)
3. กด **Apply** รอสร้างเสร็จ (ไม่กี่นาที) จะได้ลิงก์แบบ `https://fdnc.onrender.com` (ชื่อมาจาก `name:` ใน `render.yaml` ถ้ามีคนใช้ชื่อนี้แล้ว Render จะต่อท้ายด้วยตัวอักษรสุ่ม)
4. เปิดลิงก์นั้น กด "🌐 เล่นออนไลน์"

### เปลี่ยนชื่อลิงก์ .onrender.com

Render เปลี่ยนชื่อลิงก์ของบริการที่สร้างแล้วไม่ได้ ให้แก้ `name:` ใน `render.yaml` แล้วลบบริการเดิม (Settings → Delete Web Service) และทำขั้นที่ 2–3 ใหม่ ลิงก์เดิมจะใช้ไม่ได้อีก ห้องที่ค้างอยู่จะหาย

แบบฟรีของ Render หลับเมื่อไม่มีคนเข้า 15 นาที คนแรกที่เปิดจะรอให้ตื่นราวหนึ่งนาที และห้องที่เล่นค้างอยู่จะหายเมื่อเซิร์ฟเวอร์หลับหรือรีสตาร์ต

## หน้าแอดมิน (แก้รูป ข้อความ เสียง CSS ของทั้งเว็บ)

เข้าทางลิงก์ลับ: `https://fdnc.onrender.com/admin?key=รหัสแอดมิน` รหัสผิดหรือไม่ใส่จะขึ้น "not found" เหมือนไม่มีหน้านี้ ใส่ผิด 8 ครั้งใน 15 นาที ที่อยู่นั้นถูกปิด 15 นาที เซิร์ฟเวอร์ตรวจรหัสทุกครั้งที่บันทึก

ตั้งค่าบน Render (Dashboard → บริการ fdnc → **Environment** → Add Environment Variable แล้ว Save):

1. `ADMIN_KEY` = รหัสแอดมินที่ตั้งเอง (ยาว 12 ตัวขึ้นไป อย่าใส่ใน repo) ไม่ตั้ง = ปิดหน้าแอดมิน
2. `GITHUB_TOKEN` = โทเคน GitHub ให้เก็บการแก้ไขถาวร (Render แบบฟรีลบดิสก์ทุกครั้งที่เซิร์ฟเวอร์หลับหรือรีสตาร์ต ถ้าไม่ตั้ง การแก้ไขจะหายภายในไม่กี่ชั่วโมง)
   - สร้างที่ GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: Only select repositories → `bookba/fate-dark-night-city`
   - Permissions → Repository permissions → **Contents: Read and write**
   - การแก้ไขถูกเก็บใน branch `admin-data` โฟลเดอร์ `admin-data/` (ไม่แตะ branch ของเกม)
3. `GITHUB_REPO` = `bookba/fate-dark-night-city` และ `GITHUB_BRANCH` = `admin-data` (มีใน `render.yaml` แล้ว)

ในหน้าแอดมิน:

- **แก้บนหน้าเกม**: เปิดเกมในโหมดแก้ไข กด "✏️ แก้ไข" แล้วแตะข้อความหรือรูปไหนก็ได้เพื่อเปลี่ยน (แยกตามภาษา)
- **รูปภาพ**: รูปทั้งหมดในเว็บ เปลี่ยน/คืนรูปเดิม รูปใหม่ขึ้นที่อยู่เดิม ทุกจุดในเกมเปลี่ยนตาม
- **เสียง**: ใส่ไฟล์เสียงแทนเสียงแต่ละแบบในเกม ฟังเทียบเสียงเดิมกับเสียงใหม่ได้
- **ข้อความ (ทุกภาษา)**: ทุกข้อความในพจนานุกรมภาษา (`v5/i18n.js`) ไทย อังกฤษ จีน ญี่ปุ่น
- **สี / CSS**: CSS เพิ่มเติมสำหรับเปลี่ยนสี ตัวอักษร ขนาด
- **สำรอง / ที่เก็บ**: สถานะที่เก็บ ดาวน์โหลดไฟล์สำรอง นำกลับมา คืนค่าเดิมทั้งเว็บ

ผู้เล่นเห็นการแก้ไขเมื่อเปิดหรือรีเฟรชหน้าเกม เดโมใน Claude artifact ไม่มีเซิร์ฟเวอร์ จึงเป็นแบบเดิมเสมอ

ลองบนเครื่อง: `ADMIN_KEY=test node server/index.mjs` แล้วเปิด http://localhost:8080/admin?key=test (Windows PowerShell: `$env:ADMIN_KEY="test"; node server/index.mjs`)

## ไฟล์

- `server/index.mjs` เว็บเซิร์ฟเวอร์ (ส่งหน้า `v5/` และรูปการ์ด) และ WebSocket ที่ `/ws`
- `server/room.mjs` ห้อง ที่นั่ง ใครตอบคำถามไหน เวลาคิด และคำตอบตอนหมดเวลา
- `server/ws.mjs` WebSocket ขนาดเล็กที่เขียนเอง
- `v5/net.js` วิธีส่งเกมไปหน้าเว็บ และสิ่งที่แต่ละคนห้ามเห็น (ใช้ทั้งเซิร์ฟเวอร์และหน้าเว็บ)
- `v5/online.js` หน้าเว็บฝั่งออนไลน์: ล็อบบี้ ป้ายห้อง นาฬิกาเวลาคิด
- `server/admin.mjs` หน้าแอดมิน: ตรวจรหัส เก็บการแก้ไข (ดิสก์ + GitHub) ส่งรูป/ข้อความ/เสียงที่แก้ให้ผู้เล่น
- `server/admin.html` หน้าแอดมิน
- `v5/custom.js` หน้าเกมรับการแก้ไข (ข้อความบนหน้าจอ CSS) · `v5/admin-edit.js` โหมดแก้บนหน้าเกม
