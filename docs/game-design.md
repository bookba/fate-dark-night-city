## 1. ภาพรวม

- **ผู้เล่น:** 8 Master ช่องว่างเติมบอท
- **ความยาว:** 8 วัน = 16 เฟส ประมาณ 12–15 นาที (ข้อ 4)
- **ทั้งหมดที่ต้องรู้:** กลางวันเลือกพื้นที่และสะสมมานา · กลางคืนลงการ์ด 2 ใบ + ทอย 1d6 แข่งพลังรวมในพื้นที่ · ชนะได้รางวัล แพ้เสีย HP · Servant ตายใช้ Command Seal อัญเชิญใหม่ · ช่วงท้ายแย่งจอก
- **ไม่มีการผลัดเทิร์น:** ทุกขั้นทุกคนเลือกพร้อมกันภายในตัวจับเวลาเดียว แล้วเปิดผลพร้อมกัน ไม่มีการตัดสินใจหลังเห็นผล

## 4. หนึ่งวัน

ทุกขั้นในเกม **ทุกคนเลือกพร้อมกัน** ภายในตัวจับเวลาเดียว แล้ว server เปิดผลทีเดียว ไม่มีใครต้องรอใครเล่น
- ถ้าทุกคนที่มีตัวเลือกกดยืนยันครบ ขั้นนั้นจบทันที
- คนที่ไม่มีอะไรให้เลือกในขั้นนั้น (เช่น ไม่ได้สู้ในขั้นลงการ์ด) ไม่ต้องกดอะไร หน้าจอแสดงว่ารออะไรอยู่
- **ทุกอย่างที่ใช้ได้** (Command Seal, การ์ดไอเท็ม, สกิล) ต้องเลือกภายในขั้นที่ระบุในข้อ 8 และ 10 เท่านั้น ไม่มีช่วงแทรกหลังเปิดผล

| ขั้น | เวลา | ใครต้องเลือก |
|---|---|---|
| กลางวัน: เลือกพื้นที่ (+ สนามรบสำรอง, ธุระโบสถ์, ไอเท็มกลางวัน) | 30 วิ | ทุกคน |
| เปิดผลกลางวัน | ~5 วิ | — |
| กลางคืน: ย้าย / อยู่ที่เดิม / "หนี!" / เป้าหมายของคนในโบสถ์ | 15 วิ | คนที่ย้ายได้ คนที่มี Command Seal หรือม้วนคาถา และคนในโบสถ์ |
| เปิดผลการย้าย | ~3 วิ | — |
| กลางคืน: ลงการ์ด (+ เพิ่มพลัง!, รักษา!, ไอเท็มต่อสู้) | 20 วิ | คนที่ต้องสู้ |
| เปิดการ์ด + ลูกเต๋า + ผล (ทุกพื้นที่แสดงพร้อมกันแบบแบ่งจอ) | ~15 วิ | — |

หนึ่งวันใช้เต็มที่ประมาณ 90 วินาที (เร็วกว่านี้ถ้าทุกคนกดครบก่อน) 8 วันประมาณ 12 นาที รวมช่วงเริ่ม/จบเกมประมาณ 12–15 นาที

### 4.1 กลางวัน: เตรียมการ (ไม่มีการต่อสู้)
1. **จั่ว** ให้มือครบ 3 ใบ
2. **เปิดการ์ดสถานการณ์** ของคืนนี้ (ข้อ 7) วางการ์ดอีเวนต์ที่มิยามะ (เปิด) กับชินโตะ (คว่ำ) และเปิดเควส 3 ใบของวันนี้ที่โบสถ์
3. **เลือกพร้อมกัน** (30 วิ)
   - พื้นที่ 1 แห่ง ถ้าเลือกวัดหรือโบสถ์ ต้องเลือกสนามรบสำรองด้วย
   - ถ้าเลือกโบสถ์: เลือกธุระโบสถ์ไว้เลย (ถวายมานา หรือเควสใบไหน)
   - ไอเท็ม/Command Seal ที่ใช้กลางวันได้ (ข้อ 8, 10) และทิ้งไอเท็มที่เกิน
   - ถ้าได้ "วัตถุเชื่อมโยง" ค้างอยู่: เลือก Servant 1 ใน 3 ที่สุ่มมาให้ (ข้อ 9)
4. **เปิดพร้อมกัน** แล้วจัดคนเกินความจุ: วัดให้คนที่มี **มานาน้อยที่สุด** ได้ก่อน โบสถ์ให้คนที่มี **Command Seal น้อยที่สุด** ได้ก่อนแล้วค่อยดูมานา เสมอกันสุ่ม คนที่ไม่ได้เข้าไปอยู่สนามรบสำรอง (ธุระโบสถ์ที่เลือกไว้ถือว่ายกเลิก ไม่เสียอะไร) ⚠️
5. ทุกคนเห็นตำแหน่งสุดท้ายของทุกคน แล้วได้ผลกลางวัน (มานาที่วัด, ธุระโบสถ์)

### 4.2 กลางคืน: ปฏิบัติการและต่อสู้
1. **เปิด** การ์ดอีเวนต์ที่ชินโตะ
2. **ย้ายพร้อมกัน** (15 วิ) ตัวเลือกของแต่ละคน:
   - **อยู่ที่เดิม**
   - **ย้ายไปสนามรบ** (จ่าย 2 มานา) ได้เฉพาะคนที่ **ไม่ติดพัน** คือคนที่อยู่พื้นที่ของตัวเองคนเดียวตามตำแหน่งสุดท้ายของกลางวัน (อยู่สนามรบคนเดียวย้ายไปอีกสนามรบได้ · อยู่วัดหรือโบสถ์คนเดียวย้ายไปสนามรบไหนก็ได้)
   - **"หนี!"** (Command Seal หรือม้วนคาถาเคลื่อนย้าย) ไปพื้นที่ไหนก็ได้ แม้ติดพัน
   - คนในโบสถ์เลือกเป้าหมายที่จะดูมือ
   - ย้ายเข้าวัดหรือโบสถ์ได้ด้วย "หนี!" เท่านั้น **ที่ว่าง** นับจากตำแหน่งสุดท้ายของกลางวันเทียบกับความจุ (คนที่หนีออกพร้อมกันไม่ทำให้มีที่ว่างเพิ่ม) ถ้าคนหนีเข้าเกินที่ว่าง ใช้ลำดับสิทธิ์เดียวกับกลางวัน คนที่ไม่ได้เข้า **อยู่ที่เดิม** และได้ Command Seal หรือม้วนคาถาคืน
   - เปิดพร้อมกัน จึงไม่รู้ว่าคนอื่นจะย้ายตามมาหรือเปล่า
3. **ลงการ์ดพร้อมกัน** (20 วิ) ทุกคนที่ต้องสู้เลือกการ์ด 2 ใบแบบลับและจ่ายมานารวม (ลงคว่ำได้ = 0 พลัง ไม่เสียมานา) พร้อมกับเลือก "เพิ่มพลัง!", "รักษา!" และไอเท็มต่อสู้ในขั้นนี้เลย
4. **เปิดพร้อมกัน แล้ว server คิดผลตามลำดับนี้ในครั้งเดียว**
   1. "รักษา!" และไอเท็มฟื้น HP
   2. ทอยลูกเต๋า (รวมลูกที่ทอยเพิ่ม ข้อ 6)
   3. คำนวณพลังรวม · ถ้าใครลง NP ชื่อจริงถูกเปิดหลังคำนวณ (จุดอ่อน −2 มีผลตั้งแต่การต่อสู้ครั้งถัดไป)
   4. คิดดาเมจ แล้วเช็กว่าใครตาย
   5. แจกรางวัล ธงยึดครอง จอก และของที่ยึดจากผู้ตาย
5. **อัญเชิญใหม่อัตโนมัติ** สำหรับ Servant ที่ตาย (ข้อ 9) ไม่ต้องรอใครเลือก
6. ทิ้งการ์ดที่ใช้ (การ์ด NP กลับไปวางข้างตัว ใช้ซ้ำได้)

### 4.3 หมดเวลาและหลุดจากเกม
- **ไม่เลือกภายในเวลา:** กลางวัน = สนามรบเดิมถ้ายังเปิด ไม่งั้นสุ่มสนามรบ (วันแรกสุ่มสนามรบ) และไม่ใช้ธุระโบสถ์ · ย้าย = อยู่ที่เดิม · ลงการ์ด = **บอทเลือกการ์ดให้** (ไม่ใช่ลงคว่ำ) เพื่อไม่ให้เน็ตกระตุกทำให้แพ้ฟรี
- ตัวจับเวลาของ server เป็นตัวตัดสิน และรับคำตอบช้าได้อีก 1 วินาที
- **หลุดกลางเกม:** ถ้าพลาด 1 ขั้นและยังไม่กลับมา บอทเล่นแทนทันที ผู้เล่นกลับมาเมื่อไรก็ได้ เริ่มเล่นเองตั้งแต่ขั้นถัดไป
- **ตกรอบแล้ว:** ดูต่อแบบผู้ชมได้ (เห็นแค่ข้อมูลที่เปิดแล้ว) หรือออกจากห้องก็ได้ ผลอันดับแสดงตอนจบ

ผลพิเศษของการ์ดทุกใบต้องทำงานเองตอนเปิดผล ห้ามมีผลที่ต้องให้ผู้เล่นตัดสินใจหลังเห็นผล

การกระจายประเภทของการ์ดโจมตีบอกใบ้คลาส เช่น Archer มีการ์ดว่องไวเยอะ Caster มีการ์ดเวทเยอะ คู่แข่งจึงเดาตัวตนได้จากการ์ดที่เราลง

**ตัวอย่างสำรับ: Artoria**
- โจมตี: กำลัง 2, 3, 4, 4, 5 · ว่องไว 2, 3 · เวท 1, 2, 3
- สกิล: **ปลดปล่อยมานา** (พลัง 4, มานา 3, ถ้าคู่กับการ์ดกำลัง พลัง +3) · **สัญชาตญาณ** (พลัง 1, มานา 2, ทอยลูกเต๋าเพิ่ม 1 ลูก)
- NP: **Excalibur** (พลัง 10, มานา 8, ถ้าชนะ ทุกคนที่แพ้ในพื้นที่เสีย HP +2)

ตัวเลขทั้ง 14 สำรับเก็บใน `shared/servants.json` ทำเป็นตารางตอนบาลานซ์ ⚠️

### 5.3 ชื่อจริง
- การ์ดที่มีป้าย **"เปิดชื่อจริง"** (NP ทุกใบ) พลิกการ์ด Servant ให้ทุกคนเห็น: ชื่อ, สำรับทั้งหมด และพื้นที่ถนัด/ไม่ถนัด
- **จุดอ่อน:** เมื่อชื่อจริงถูกเปิด Servant ตนนั้นได้พลังรวม −2 ทุกการต่อสู้ (คู่แข่งรู้วิธีรับมือ) เริ่มตั้งแต่การต่อสู้ครั้งถัดไป จนกว่าจะตาย (ตนใหม่ที่อัญเชิญมาเป็นความลับอีกครั้ง) · ใช้ −2 กับตัวเองแทน +2 ให้คู่แข่ง เพื่อให้คิดง่ายในตะลุมบอน ⚠️

## 6. การต่อสู้: การ์ด + ลูกเต๋า

**พลังรวม = การ์ด 2 ใบ + โบนัสพื้นที่ + การ์ดสถานการณ์ + พื้นที่ถนัด (±2) + ชื่อจริงถูกเปิดแล้ว (−2) + ผู้ถือจอก (+3) + ลูกเต๋า + "เพิ่มพลัง!" (+4) + อัญมณีของโทซากะ (+4)**

- **ลูกเต๋า:** ปกติทอย 1d6 · ผลที่ให้ "ทอยเพิ่ม 1 ลูก" (จันทร์เต็มดวง, สกิลสัญชาตญาณ, เครื่องรางนำโชค) ซ้อนกันได้ ผลละ 1 ลูก แล้วใช้ลูกที่ค่าสูงสุด ระบบทอยให้อัตโนมัติ ไม่มีการทอยใหม่หลังเห็นผล
- การ์ดอีเวนต์เป็นรางวัล ไม่ได้เพิ่มพลัง

### 6.1 โบนัสพื้นที่และธงยึดครอง

| สถานะในสนามรบนั้น | โบนัส |
|---|---|
| **ยึดครอง:** ถือธงของสนามรบนี้ และอยู่ที่นี่ตั้งแต่กลางวัน | +3 |
| **ตั้งหลัก:** อยู่ที่นี่ตั้งแต่กลางวัน (รวมคนที่ถูกส่งมาจากการเกินความจุ) | +1 |
| **บุกเข้ามา:** ย้ายหรือ "หนี!" เข้ามาตอนกลางคืน | 0 |

**ธงยึดครอง** สนามรบละ 1 ผืน
- จบคืน ธงไปอยู่กับผู้ชนะที่สนามรบนั้น หรือคนที่อยู่คนเดียว
- เสมอสูงสุด: ถ้าเจ้าของธงเดิมอยู่ในกลุ่มที่เสมอ เก็บธงไว้ ไม่งั้นธงว่าง
- มอนสเตอร์ชนะ หรือไม่มีใครอยู่ตอนจบคืน: ธงว่าง
- เจ้าของธงที่ไม่ได้อยู่สนามรบนั้นตอนจบคืน (ย้ายออกหรือหนี) เสียธง
- วัดริวโดไม่มีธงและโบนัสพื้นที่ ⚠️

### 6.2 ผลการต่อสู้

| ผล | กติกา |
|---|---|
| **ผู้ชนะ** (พลังรวมสูงสุด) | ได้รางวัลของพื้นที่ |
| **ผู้แพ้** | เสีย HP = พลังรวมของผู้ชนะ − พลังรวมของตัวเอง (ขั้นต่ำ 1) |
| **เสมอสูงสุด** | คนที่เสมอแบ่งรางวัล (ปัดขึ้น) และไม่เสีย HP · คนอื่นในพื้นที่เสีย HP ตามส่วนต่างกับค่าสูงสุดตามปกติ |
| **ฆ่าได้** | ผู้ชนะยึดมานาครึ่งหนึ่ง และการ์ดไอเท็ม 1 ใบ (สุ่ม) ของผู้ตาย · ถ้าเสมอสูงสุด ไม่มีใครยึด |

### 6.3 ตะลุมบอน (3 คนขึ้นไปในพื้นที่เดียว)
ใช้กติกาเดียวกันทั้งหมด ทุกคนลงการ์ดพร้อมกัน เทียบครั้งเดียว:
- คนที่สูงสุดชนะคนเดียว ได้รางวัล **+2 มานาโบนัส** (ถ้าเสมอสูงสุด แบ่งโบนัสด้วย)
- **ทุกคนที่เหลือ** เสีย HP ตามส่วนต่างกับค่าสูงสุด จึงอันตรายกว่าการดวล
- มอนสเตอร์นับเป็นผู้เข้าร่วม 1 ตน

## 7. การ์ดสถานการณ์และการ์ดอีเวนต์

**การ์ดสถานการณ์** (เปิด 1 ใบตอนเช้า ให้ทุกคนวางแผนได้ มีผลคืนนั้นทุกพื้นที่) ⚠️

| การ์ด | ผล |
|---|---|
| คืนแห่งพละกำลัง | การ์ดกำลัง +2 พลัง |
| คืนแห่งความเร็ว | การ์ดว่องไว +2 พลัง |
| คืนแห่งเวทมนตร์ | การ์ดเวท +2 พลัง · ทุกคน +2 มานาตอนเช้า |
| จันทร์เต็มดวง | ทุกคนทอยเพิ่ม 1 ลูก |
| หมอกหนา | ห้ามย้ายแบบจ่ายมานาคืนนี้ ("หนี!" ยังใช้ได้) |
| เงาดำจากจอก | ประกาศสนามรบ 1 แห่งตั้งแต่เช้า คืนนั้นมีมอนสเตอร์พลัง 12 + 1d6 ร่วมสู้ ถ้ามอนสเตอร์ชนะ ไม่มีใครได้รางวัลและธง · ผู้ชนะที่ชนะมอนสเตอร์ได้การ์ดไอเท็มเพิ่ม 1 ใบ |
| ใจเดียว | ลง 2 ใบประเภทเดียวกัน +3 พลัง |
| คืนเลือด | ผู้ชนะที่ฆ่าได้ยึดมานาทั้งหมด |

**การ์ดอีเวนต์** (รางวัลของสนามรบ) ตัวอย่าง: +5 มานา · การ์ดไอเท็ม 1 ใบ · ฟื้น HP 5 · จั่วการ์ด 2 ใบ · การ์ดไอเท็ม 1 ใบ + 2 มานา

## 8. โบสถ์และ Command Seal

### Command Seal (เริ่ม 3 ดวง สูงสุด 3)

| คำสั่ง | เลือกในขั้น | ผล |
|---|---|---|
| **หนี!** | กลางคืน: ย้าย | ย้ายไปพื้นที่ไหนก็ได้แม้ติดพัน ไม่เสียมานา (เข้าวัด/โบสถ์ตามกติกาที่ว่างในข้อ 4.2) |
| **เพิ่มพลัง!** | กลางคืน: ลงการ์ด (เลือกพร้อมการ์ด) | พลังรวม +4 |
| **รักษา!** | กลางวัน หรือ กลางคืน: ลงการ์ด | ฟื้น HP 50% (ถ้าเลือกตอนลงการ์ด ฟื้นก่อนคิดดาเมจ) |
| **อัญเชิญ** | อัตโนมัติเมื่อ Servant ตาย | อัญเชิญ Servant ใหม่ (ข้อ 9) |

### ธุระโบสถ์ (เลือกพร้อมกับการเลือกพื้นที่ตอนกลางวัน)
- **ถวายมานา:** แลก Command Seal 1 ดวง ราคา 10 / 14 / 18 มานา (ขึ้นทุกครั้งที่แลก)
- **รับเควส** 1 ใน 3 ใบของวันนั้น (มัดจำ 2 มานา ทำสำเร็จได้ Command Seal ทันที ถือได้ทีละ 1 เควส) ⚠️
  - ล่าค่าหัว: ทำให้ Servant ตนไหนก็ได้ตาย ภายใน 2 วัน
  - ชนะสนามรบ: ชนะการต่อสู้ที่มิยามะหรือชินโตะ 2 ครั้ง ภายใน 3 วัน
  - ล่าวีรชนที่เปิดเผยแล้ว: ชนะการต่อสู้กับ Servant ที่ชื่อจริงถูกเปิดแล้ว ภายใน 3 วัน
  - เครื่องบูชา: มอบการ์ดไอเท็ม 2 ใบ (ทันที)
- แลกได้วันละ 1 ดวงต่อคน · ผู้ถือจอกใช้โบสถ์ไม่ได้

## 9. ความตายและการอัญเชิญใหม่

- HP หมด = Servant ตาย นับเข้าตัวนับรวม (ครบ 7 → จอกปรากฏ)
- **อัตโนมัติ:** ใช้ Command Seal 1 ดวง อัญเชิญ Servant ใหม่แบบสุ่มจากกองกลาง สำรับใหม่ มือใหม่ 3 ใบ เล่นได้ตั้งแต่กลางวันถัดไป · ตายหลายคนในคืนเดียวกัน server สุ่มให้ทุกคนพร้อมกัน
- ผู้ที่มี "วัตถุเชื่อมโยง": เลือก Servant 1 ใน 3 ตนที่สุ่มจากกองกลางในขั้นกลางวันถัดไป (ไม่แสดงกองทั้งหมด กันการเดาว่าใครใช้ตนไหน) หมดเวลา = สุ่ม
- ไม่มี Command Seal เหลือ → Master ตกรอบ
- มานา Command Seal และไอเท็มเป็นของ Master ยังอยู่ (ยกเว้นที่ผู้ชนะยึด)

## 11. จอกศักดิ์สิทธิ์

- ปรากฏเมื่อตายรวมครบ 7 ครั้ง หรือเริ่มวันที่ 8 · ประกาศตอนเช้าของวันถัดไป และวาง **เปิดหน้า** ที่สนามรบ 1 แห่งที่ยังเปิด (สุ่ม) ทุกคนรู้ว่าจอกอยู่ไหนก่อนเลือกพื้นที่
- จบคืน จอกไปอยู่กับผู้ชนะที่สนามรบนั้น หรือคนที่อยู่คนเดียว · เสมอสูงสุดหรือมอนสเตอร์ชนะ จอกยังวางอยู่ที่เดิม
- ผู้ถือจอก: พลังรวม +3 ทุกการต่อสู้ · ต้องลงสนามรบเท่านั้น ห้ามเลือกหรือหนีเข้าวัดและโบสถ์
- ผู้ถือจอกแพ้การต่อสู้ → จอกไปที่ผู้ชนะ · เสมอสูงสุดกับผู้ถือ → ผู้ถือเก็บจอกไว้ · ผู้ถือตกรอบ → จอกไปที่ผู้ชนะในพื้นที่นั้น
- **เกมจบ** เมื่อจบคืนวันที่ 8 (ถ้าจอกปรากฏก่อนนั้น ให้เล่นต่ออีก 2 วัน แต่ไม่เกินวันที่ 8 ⚠️) หรือเหลือ Master คนเดียว
- **ผู้ชนะ** = ผู้ถือจอกตอนเกมจบ ถ้าไม่มี ผู้มีมานามากสุดชนะ

## 12. บอท

บอทใช้ **ข้อมูลเดียวกับที่ผู้เล่นคนนั้นเห็น** เท่านั้น (ไม่อ่านการ์ดคว่ำ มือคนอื่น หรือคำตอบที่ยังไม่เปิด) และทำตามข้อจำกัดเดียวกับผู้เล่น

- **กลางวัน:** เลือกจากพื้นที่ที่ยังเปิดเท่านั้น · มานา < 8 → วัด · Command Seal ≤ 1 และมานาพอ → โบสถ์ · ผู้ถือจอก → สนามรบเสมอ · อื่นๆ → สนามรบที่รางวัลดีและเป็นพื้นที่ถนัด (ไม่ทุกครั้ง กันถูกจับทาง) · เลือกสนามรบสำรองทุกครั้งที่เลือกวัดหรือโบสถ์
- **กลางคืน:** ย้ายเฉพาะตอนไม่ติดพัน และสนามรบอีกแห่งดูอ่อนกว่า (ประเมินจาก HP มานา และคลาสที่เห็น) · ลงการ์ดคู่ที่พลังสูงสุดที่จ่ายไหว · ใช้ NP เมื่อประเมินว่าโอกาสชนะสูง หรือเป็นการต่อสู้ชิงจอก · ใช้ "เพิ่มพลัง!" เมื่อชิงจอก · ใช้ "หนี!" เมื่อ HP ต่ำมากและเหลือ Command Seal ≥ 2
- **ระดับยาก:** จำการ์ดที่คู่แข่งลงเพื่อเดาตัวตนและพื้นที่ถนัด
- **เล่นแทนคนที่หลุด** ด้วยกติกาเดียวกัน

## 13. สถาปัตยกรรมเครือข่าย

- Node.js server ถือสถานะทั้งหมด ทอยลูกเต๋า สับการ์ด จับเวลา รันบอท · client (Vite) แสดงผล ส่งแค่การเลือก
- **ทุกขั้นเลือกพร้อมกัน** มีตัวจับเวลาเดียวต่อขั้น server รับคำตอบลับจนครบหรือหมดเวลา แล้วเปิดผลทีเดียว (ไม่มีการรอเทิร์น ไม่มีช่วงแทรกหลังเปิดผล)
- **ข้อมูลลับไม่ส่งไปที่ client:** การ์ด Servant ที่คว่ำ, การ์ดในมือคนอื่น, การ์ดอีเวนต์คว่ำ, คำตอบของทุกขั้นก่อนเปิดผล (พื้นที่ สนามรบสำรอง ธุระโบสถ์ การย้าย การ์ด ไอเท็ม Command Seal), พื้นที่ถนัด, เควสที่คนอื่นถือ
- **ข้อยกเว้น:** มือของเป้าหมายส่งให้คนในโบสถ์คนเดียว · การ์ด Servant ของเป้าหมายส่งให้คนที่ใช้บันทึกวีรชนคนเดียว
- ผู้ชมที่ตกรอบเห็นเฉพาะข้อมูลที่เปิดแล้ว
- `ws` + JSON · โครงสร้าง `client/`, `server/`, `shared/` (servants, cards, areas, situations, events)

## 15. ประวัติการเปลี่ยนแปลง

### v1.1 (ตัดการผลัดเทิร์น)
- วางตัวกลางวันและย้ายตอนกลางคืน เปลี่ยนจากทีละคนตามลำดับ เป็นเลือกพร้อมกัน
- โบนัส "คนมาก่อน +3/+1" เปลี่ยนเป็น ยึดครอง +3 / ตั้งหลัก +1 / บุกเข้ามา 0 พร้อมธงยึดครอง
- พื้นที่เกินความจุ: มานาน้อยสุดได้ก่อน (วัด) · Command Seal น้อยสุดได้ก่อน (โบสถ์) · คนที่ไม่ได้เข้าไปสนามรบสำรอง
- ทุก Command Seal ไอเท็ม และสกิล มีขั้นที่ใช้ชัดเจน ไม่มีการตัดสินใจหลังเห็นผล · "ทอยใหม่" เปลี่ยนเป็น "ทอยเพิ่ม 1 ลูก ใช้ค่าสูงสุด"
- อัญเชิญใหม่อัตโนมัติ · กติกาหมดเวลา หลุดกลางเกม และผู้ชม
- จอกวางเปิดหน้าเสมอ · กติกาเสมอของรางวัล ธง และจอก · เควส "เปิดโปงวีรชน" เปลี่ยนเป็น "ล่าวีรชนที่เปิดเผยแล้ว"
