> **กติกาที่ผู้เล่นกำหนด**
> - 8 วัน วันละ 2 เฟส ผู้เล่นเลือกลงพื้นที่เพื่อเก็บทรัพยากร
> - ตายรวมครบ 7 ครั้ง หรือถึงวันที่ 8 → จอกศักดิ์สิทธิ์ปรากฏ · คนสุดท้ายที่ถือจอกชนะ
> - ไม่มีระบบแปลงร่าง · ออกท่าด้วยมานาที่เก็บได้ + ลูกเต๋าเป็นดวง
> - ใช้ Noble Phantasm แล้วชื่อจริงของ Servant ถูกเปิดเผย · Servant มีระบบสกิล
> - Servant ตาย → ต้องอัญเชิญใหม่ · Command Seal ใช้ หนี / เพิ่มพลัง / รักษา · Command Seal หมด = อัญเชิญไม่ได้อีก
>
> ส่วนที่เหลือเป็นข้อเสนอของผม ทำเครื่องหมาย ⚠️ ไว้ตรงที่ยังปรับได้

## 1. ภาพรวม

- **ผู้เล่น:** 8 Master ต่อแมตช์ ช่องว่างเติมบอท
- **ความยาว:** สูงสุด 8 วัน = 16 เฟส ประมาณ 15–20 นาที
- **หัวใจของเกม:** ซ่อนตัวตนของ Servant ให้นานที่สุด เก็บมานา เลือกจังหวะใช้ Command Seal เพราะทุกดวงคือ "ชีวิตสำรอง" แล้วแย่งจอกตอนท้าย
- **แพลตฟอร์ม:** เบราว์เซอร์ PC และมือถือ เล่นด้วยการแตะ/คลิกเลือก

## 2. ลำดับแมตช์

1. **Lobby** — ทุกคนกดพร้อม ที่ว่างเติมบอทให้ครบ 8
2. **อัญเชิญครั้งแรก** — ได้ Servant สุ่มจากกองกลาง (ข้อ 6) ฟรี ไม่เสีย Command Seal ทุกคนเห็นแค่ **คลาส** ไม่เห็นชื่อจริง
3. **วันที่ 1–8** — แต่ละวันมีเฟสกลางวันและกลางคืน
4. **จอกปรากฏ** — ตายรวมครบ 7 ครั้ง หรือเริ่มวันที่ 8
5. **ศึกชิงจอก** — ผู้ถือจอกคนสุดท้ายเมื่อเกมจบชนะ

## 3. หนึ่งเฟส (กลางวัน / กลางคืน)

ทุกคนเลือกพร้อมกันแบบลับ แล้วเปิดเผยพร้อมกัน

| ขั้น | เกิดอะไร |
|---|---|
| ① **เลือกพื้นที่** | 1 จาก 8 พื้นที่ + ท่าที: เก็บของ / ซ่อนตัว / ล่า (30 วิ) |
| ② **เปิดเผย** | แสดงว่าใครอยู่พื้นที่ไหน คนที่ซ่อนตัวสำเร็จไม่ถูกเห็น |
| ③ **ปะทะ** | อยู่พื้นที่เดียวกันและมีฝ่ายหนึ่ง "ล่า" → ต่อสู้ (ข้อ 7) |
| ④ **เก็บทรัพยากร** | คนที่ยังอยู่ทอยลูกเต๋าเก็บของ (ข้อ 4) |
| ⑤ **อัญเชิญใหม่** | Master ที่ Servant ตายในเฟสนี้เลือกจ่าย Command Seal อัญเชิญใหม่ (ข้อ 9) |

- **เก็บของ** — ได้ทรัพยากรเต็ม แต่ถูกคนที่ล่าโจมตีได้
- **ซ่อนตัว** — ได้ครึ่งเดียว ทอย d6 ≥ 4 เพื่อไม่ถูกพบ (กลางวัน ≥ 3, กลางคืน ≥ 5)
- **ล่า** — ได้ครึ่งเดียว บังคับสู้กับคนในพื้นที่ (เลือกเป้าหมายได้)
- กลางคืนได้มานา ×1.5 ⚠️ · ไม่เลือกภายในเวลา = พื้นที่เดิม + เก็บของ

| Archer | EMIYA | Unlimited Blade Works | HP ต่ำสุดในคลาส |

| Lancer | Cú Chulainn | Gáe Bolg | ห้ามหนี (geis) เมื่อถูกท้าตอนกลางคืน |

### การเปิดเผยชื่อจริง
- **ใช้ Noble Phantasm ครั้งแรก** → ทั้งห้องเห็นชื่อจริง สกิลทั้งหมด NP และจุดอ่อน
- ก่อนถูกเปิดเผย ผู้เล่นอื่นเห็นแค่คลาส ค่าสถานะ และ "สกิลที่เคยใช้ต่อหน้าเขา"
- จุดอ่อนมีผลเฉพาะกับคนที่รู้ชื่อจริงแล้ว เมื่อเปิดเผยด้วย NP ทุกคนรู้
- การ์ด "บันทึกวีรชน" (ข้อ 10) เปิดชื่อจริงของเป้าหมายให้ผู้ใช้คนเดียวรู้
- ทำให้ NP เป็นการตัดสินใจจริงจัง: ใช้แล้วแรง แต่เสียความลับ

### หนึ่งการต่อสู้
1. ทั้งคู่ทอย 1d6 + AGI สูงกว่าได้สิทธิ์ "เปิดท่าทีหลัง" ในรอบสุดท้าย ⚠️
2. ทุกรอบ ทั้งคู่เลือกท่าลับพร้อมกัน จ่ายมานาทันที
3. Server ทอยลูกเต๋า แสดงแอนิเมชัน คิดดาเมจ
4. สูงสุด 3 รอบ หรือจน Servant ฝ่ายหนึ่งตาย
5. ผู้ชนะ (ทำให้อีกฝ่ายตาย) ยึดมานาครึ่งหนึ่งของผู้แพ้ และการ์ด 1 ใบสุ่ม
6. ผู้เล่น 3 คนขึ้นไปในพื้นที่เดียว: ผู้ล่าเลือกเป้าหมาย ถ้ามีหลายผู้ล่าสู้เป็นคู่ตามลำดับ AGI

## 8. ความตายและการอัญเชิญใหม่

- Servant HP หมด = **ตาย 1 ครั้ง** นับเข้าตัวนับของแมตช์ (ครบ 7 → จอกปรากฏ)
- จบเฟส Master เลือก **จ่าย Command Seal 1 ดวง** อัญเชิญ Servant ใหม่แบบสุ่มจากกองกลาง (HP เต็ม, ชื่อจริงยังเป็นความลับ)
- **ไม่มี Command Seal เหลือ** → อัญเชิญไม่ได้ Master **ตกรอบ** (ลำดับการตกรอบคืออันดับ)
- Servant ที่ตายแล้วกลับเข้ากองกลางไม่ได้ (กองกลาง 14 ตน พอสำหรับ 8 คน + อัญเชิญใหม่ 6 ครั้ง ⚠️ ถ้าหมดให้สุ่มซ้ำได้)
- การ์ด "วัตถุเชื่อมโยง" ทำให้เลือก Servant เองได้แทนการสุ่ม

## 9. Command Seal (3 ดวง)

ทุกดวงคือทางเลือกระหว่าง "ใช้ตอนนี้" กับ "เก็บไว้เป็นชีวิตสำรอง"

| คำสั่ง | ใช้เมื่อไร | ผล |
|---|---|---|
| **หนี!** | ในการต่อสู้ แทนท่าของรอบ | ออกจากการต่อสู้แน่นอน ย้ายไปพื้นที่ที่เลือก |
| **เพิ่มพลัง!** | ในการต่อสู้ ก่อนทอย | +2 ลูกเต๋าทุกการทอยในรอบนี้ หรือใช้ NP โดยไม่เสียมานา |
| **รักษา!** | เมื่อไรก็ได้ | ฟื้น HP Servant 60% |
| **อัญเชิญ** | หลัง Servant ตาย | อัญเชิญ Servant ใหม่ (บังคับใช้ถ้าจะเล่นต่อ) |

- ได้ Command Seal คืนจากเศษที่โบสถ์โคโตมิเนะ (สูงสุด 3)
- Command Seal ที่เหลือแสดงให้ทุกคนเห็น เพื่อให้ประเมินได้ว่าใครใกล้ตกรอบ ⚠️

| กระสุนต้นกำเนิด | ตำนาน | ยกเลิก NP ของอีกฝ่าย 1 ครั้ง (มานาที่จ่ายหายไป) |
| วัตถุเชื่อมโยง | ตำนาน | อัญเชิญครั้งถัดไปเลือก Servant เองจากกองกลาง |

ได้การ์ดจากพื้นที่ (มิยามะ ชินโตะ) และจากการชนะต่อสู้ ใช้ได้ทั้งในและนอกการต่อสู้ตามที่ระบุ ⚠️

## 11. จอกศักดิ์สิทธิ์

- ปรากฏเมื่อ **ตายรวมครบ 7 ครั้ง** หรือ **เริ่มวันที่ 8** ประกาศพื้นที่ที่จอกปรากฏ (สุ่ม) ⚠️
- คนแรกที่ไปถึงได้จอก ถ้าไปพร้อมกันหลายคน ต่อสู้ ผู้ชนะได้จอก
- ผู้ถือจอก **ถูกเปิดเผยตำแหน่งทุกเฟส** ซ่อนตัวไม่ได้ ได้มานา +3 ทุกเฟส
- ผู้ถือจอกแพ้การต่อสู้ หรือตกรอบ → จอกตกเป็นของผู้ชนะ
- **เกมจบ** เมื่อจบเฟสกลางคืนวันที่ 8 (ถ้าจอกปรากฏก่อนวันที่ 8 ให้ศึกชิงจอกยาว 4 เฟส ⚠️) หรือเมื่อเหลือ Master คนเดียว
- **ผู้ชนะ** = ผู้ถือจอกตอนเกมจบ ถ้าไม่มีใครถือ ผู้มีมานามากสุดชนะ

## 12. บอท

บอทส่งคำสั่งผ่านช่องทางเดียวกับผู้เล่น ใช้แทนคนที่หลุดได้ทันที

- **พื้นที่:** ให้คะแนน = มานาที่คาดว่าได้ − ความเสี่ยง (คนที่ไปพื้นที่นั้นเฟสก่อน) แล้วสุ่มจากคะแนน
- **ท่าที:** HP < 40% → ซ่อนตัว · มานา ≥ 10 และ HP สูง → ล่า · อื่นๆ → เก็บของ
- **ต่อสู้:** ใช้สกิลเมื่อมานาพอ · ใช้ NP เมื่อจบการต่อสู้ได้หรือใกล้แพ้ · หนีเมื่อเสียเปรียบมาก
- **Command Seal:** เก็บไว้อย่างน้อย 1 ดวงเพื่ออัญเชิญเสมอ ยกเว้นช่วงชิงจอก
- **ระดับ:** ง่าย = สุ่มบ่อย · ปกติ = ตามกฎ · ยาก = คำนวณค่าคาดหวังและใช้จุดอ่อนที่รู้

## 13. สถาปัตยกรรมเครือข่าย

```
Browser (Vite)  ⇄  WebSocket  ⇄  Node.js Game Server
ส่งการเลือกพื้นที่/ท่า/การ์ด      ถือสถานะทั้งหมด, จับเวลาเฟส,
แสดงแผนที่ + ลูกเต๋า             ทอยลูกเต๋า, คำนวณผล, รันบอท
```

- **Server ทอยลูกเต๋าเท่านั้น** client แค่แสดงผล
- **ข้อมูลลับไม่ส่งไปที่ client** จนกว่าจะเปิดเผย: ชื่อจริง Servant, ท่าที่อีกฝ่ายเลือก, ใครซ่อนตัว, การ์ดในมือ
- คนหลุดแล้วกลับมาได้สถานะล่าสุด ระหว่างหลุดบอทเล่นแทน
- ไลบรารี `ws` ส่ง JSON · โครงสร้าง `client/`, `server/` (room, phase, combat, bot), `shared/` (servants, areas, cards, สูตร)
