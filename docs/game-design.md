## 1. ภาพรวม

- **ผู้เล่น:** 8 Master ช่องว่างเติมบอท
- **ความยาว:** สูงสุด 8 วัน วันละ 3 เฟส (กลางวัน → กลางคืน 1 → กลางคืน 2) · ส่วนใหญ่จอกปรากฏราววันที่ 4–5 และเกมจบราววันที่ 5–6 ประมาณ 15 นาที (ข้อ 4, 11)
- **ทั้งหมดที่ต้องรู้:** ทุกเช้าเปิดอีเวนต์ประจำวัน · กลางวันเลือกพื้นที่และสะสมมานา · กลางคืนมี 2 เฟส แต่ละเฟสลงการ์ด 2 ใบ + ทอย 1d6 แข่งพลังรวมในพื้นที่ · ชนะได้รางวัล แพ้เสีย HP · Servant ตายใช้ Command Seal อัญเชิญใหม่ · ช่วงท้ายแย่งจอก
- **ไม่มีการผลัดเทิร์น:** ทุกขั้นทุกคนเลือกพร้อมกันภายในตัวจับเวลาเดียว แล้วเปิดผลพร้อมกัน ไม่มีการตัดสินใจหลังเห็นผล

## 2. ของที่ผู้เล่นแต่ละคนมี

| ของ | รายละเอียด |
|---|---|
| **Servant** (การ์ดตัวตน คว่ำไว้) | สุ่มจากกองกลาง 14 ตน คนอื่นเห็นแค่คลาส |
| **สำรับ Servant 13 ใบ** | การ์ดโจมตี 10 ใบ + การ์ดสกิล 2 ใบ + การ์ด NP 1 ใบ (ข้อ 5) · กองจั่วหมดให้สับกองทิ้งกลับมาใช้ |
| **มือ** | จั่วให้ครบ 3 ใบ ตอนเช้า และตอนเริ่มกลางคืน 2 · การ์ด NP ที่ใช้แล้ววางข้างตัว ไม่นับในมือ และเลือกลงเป็น 1 ใน 2 ใบได้ทุกเฟส |
| **HP** | ตามคลาส (ข้อ 5.1) |
| **มานา** | เริ่ม 5 ใช้จ่ายการ์ดและการย้ายพื้นที่ สูงสุด 20 · ทุกคนเห็นมานาของกันและกัน |
| **Command Seal** | เริ่ม 3 ดวง · ทุกคนเห็นจำนวน |
| **การ์ดไอเท็ม** | ถือได้ 2 ใบ (ได้เกินชั่วคราวได้ ต้องทิ้งให้เหลือ 2 ในกลางวันถัดไป หมดเวลา = ทิ้งใบเก่าสุด) |

## 3. พื้นที่ (5 แห่ง)

| พื้นที่ | รับได้ | กลางวัน | กลางคืน |
|---|---|---|---|
| **วัดริวโด** (โรงเวท) | 3 คน | แบ่งเลย์ไลน์: อยู่คนเดียว +4 มานา · 2 คน คนละ +3 · 3 คน คนละ +2 | ทุกเฟสกลางคืน 2 คนขึ้นไปต้องสู้แย่งเลย์ไลน์ ผู้ชนะ +4 มานา · ไม่มีโบนัสพื้นที่ |
| **ย่านมิยามะ** (สนามรบ) | ไม่จำกัด | ตั้งหลักรอโบนัสพื้นที่ (ข้อ 6.1) | สู้แย่งการ์ดรางวัล · กลางคืน 1: ใบที่ **เปิดหน้า** ตั้งแต่กลางวัน · กลางคืน 2: ใบใหม่ |
| **ย่านชินโตะ** (สนามรบ) | ไม่จำกัด | ตั้งหลักรอโบนัสพื้นที่ (ข้อ 6.1) | สู้แย่งการ์ดรางวัล · กลางคืน 1: ใบที่ **คว่ำหน้า** เปิดตอนเริ่มกลางคืน 1 · กลางคืน 2: ใบใหม่ |
| **โบสถ์โคโตมิเนะ** | 1 คน | ธุระโบสถ์ (ข้อ 8) | ปลอดภัย ไม่ต้องสู้ · ทุกเฟสกลางคืน เลือกผู้เล่น 1 คนในขั้นย้าย แล้วเห็นมือของเขาตอนเริ่มขั้นลงการ์ด |

## 4. หนึ่งวัน

ทุกขั้นในเกม **ทุกคนเลือกพร้อมกัน** ภายในตัวจับเวลาเดียว แล้ว server เปิดผลทีเดียว ไม่มีใครต้องรอใครเล่น
- ถ้าทุกคนที่มีตัวเลือกกดยืนยันครบ ขั้นนั้นจบทันที
- คนที่ไม่มีอะไรให้เลือกในขั้นนั้น (เช่น ไม่ได้สู้ในขั้นลงการ์ด) ไม่ต้องกดอะไร หน้าจอแสดงว่ารออะไรอยู่
- **ทุกอย่างที่ใช้ได้** (Command Seal, การ์ดไอเท็ม, สกิล) ต้องเลือกภายในขั้นที่ระบุในข้อ 8 และ 10 เท่านั้น ไม่มีช่วงแทรกหลังเปิดผล

| ขั้น | เวลา | ใครต้องเลือก |
|---|---|---|
| กลางวัน: เลือกพื้นที่ (+ สนามรบสำรอง, ธุระโบสถ์, ไอเท็มกลางวัน) | 30 วิ | ทุกคน |
| เปิดผลกลางวัน | ~5 วิ | — |
| กลางคืน 1: ย้าย / อยู่ที่เดิม / "หนี!" / เป้าหมายของคนในโบสถ์ | 15 วิ | คนที่ย้ายได้ คนที่มี Command Seal หรือม้วนคาถา และคนในโบสถ์ |
| เปิดผลการย้าย | ~3 วิ | — |
| กลางคืน 1: ลงการ์ด (+ เพิ่มพลัง!, รักษา!, ไอเท็มต่อสู้) | 20 วิ | คนที่ต้องสู้ |
| เปิดการ์ด + ลูกเต๋า + ผล (ทุกพื้นที่แสดงพร้อมกันแบบแบ่งจอ) | ~15 วิ | — |
| กลางคืน 2: ย้าย (เหมือนกลางคืน 1) | 15 วิ | เหมือนกลางคืน 1 ยกเว้นคนที่ Servant เพิ่งตาย |
| เปิดผลการย้าย | ~3 วิ | — |
| กลางคืน 2: ลงการ์ด | 20 วิ | คนที่ต้องสู้ |
| เปิดการ์ด + ลูกเต๋า + ผล | ~15 วิ | — |

หนึ่งวันใช้เต็มที่ประมาณ 2 นาที 20 วินาที (เร็วกว่านี้ถ้าทุกคนกดครบก่อน) · จากการจำลองบอทเล่น 400 เกม เกมจบเฉลี่ยราววันที่ 5–6 (จอกปรากฏเร็วขึ้นเพราะตายบ่อยขึ้น) รวมช่วงเริ่ม/จบเกมประมาณ 15 นาที ถ้าลากถึงวันที่ 8 ประมาณ 20 นาที

### 4.1 กลางวัน: เตรียมการ (ไม่มีการต่อสู้)
1. **จั่ว** ให้มือครบ 3 ใบ
2. **เปิดการ์ดอีเวนต์ประจำวัน** (มีผลทั้งวัน ข้อ 7) วางการ์ดรางวัลที่มิยามะ (เปิด) กับชินโตะ (คว่ำ) และเปิดเควส 3 ใบของวันนี้ที่โบสถ์
3. **เลือกพร้อมกัน** (30 วิ)
   - พื้นที่ 1 แห่ง ถ้าเลือกวัด โบสถ์ หรือคฤหาสน์ ต้องเลือกสนามรบสำรองด้วย
   - ถ้าเลือกโบสถ์: เลือกธุระโบสถ์ไว้เลย (ถวายมานา หรือเควสใบไหน)
   - ถ้าเลือกคฤหาสน์: เลือกการ์ดในมือ 1–2 ใบที่จะหลอม
   - ไอเท็ม/Command Seal ที่ใช้กลางวันได้ (ข้อ 8, 10) และทิ้งไอเท็มที่เกิน
   - ถ้าได้ "วัตถุเชื่อมโยง" ค้างอยู่: เลือก Servant 1 ใน 3 ที่สุ่มมาให้ (ข้อ 9)
4. **เปิดพร้อมกัน** แล้วจัดคนเกินความจุ: วัดและคฤหาสน์ให้คนที่มี **มานาน้อยที่สุด** ได้ก่อน โบสถ์ให้คนที่มี **Command Seal น้อยที่สุด** ได้ก่อนแล้วค่อยดูมานา เสมอกันสุ่ม คนที่ไม่ได้เข้าไปอยู่สนามรบสำรอง (ธุระโบสถ์หรือการหลอมที่เลือกไว้ถือว่ายกเลิก ไม่เสียอะไร) ⚠️
5. ทุกคนเห็นตำแหน่งสุดท้ายของทุกคน แล้วได้ผลกลางวัน (มานาที่วัด, ธุระโบสถ์, หลอมการ์ด)

### 4.2 กลางคืน 1: ปฏิบัติการและต่อสู้
1. **เปิด** การ์ดรางวัลที่ชินโตะ
2. **ย้ายพร้อมกัน** (15 วิ) ตัวเลือกของแต่ละคน:
   - **อยู่ที่เดิม**
   - **ย้ายไปสนามรบ** (จ่าย 2 มานา) ได้เฉพาะคนที่ **ไม่ติดพัน** คือคนที่อยู่พื้นที่ของตัวเองคนเดียวตาม **ตำแหน่งเริ่มเฟส** (กลางคืน 1 = ตำแหน่งสุดท้ายของกลางวัน · กลางคืน 2 = ตำแหน่งตอนจบกลางคืน 1) (อยู่สนามรบคนเดียวย้ายไปอีกสนามรบได้ · อยู่วัด โบสถ์ หรือคฤหาสน์คนเดียวย้ายไปสนามรบไหนก็ได้)
   - **"หนี!"** (Command Seal หรือม้วนคาถาเคลื่อนย้าย) ไปพื้นที่ไหนก็ได้ แม้ติดพัน
   - คนในโบสถ์เลือกเป้าหมายที่จะดูมือ
   - ย้ายเข้าวัด โบสถ์ หรือคฤหาสน์ได้ด้วย "หนี!" เท่านั้น **ที่ว่าง** นับจากตำแหน่งเริ่มเฟสเทียบกับความจุ (คนที่หนีออกพร้อมกันไม่ทำให้มีที่ว่างเพิ่ม) ถ้าคนหนีเข้าเกินที่ว่าง ใช้ลำดับสิทธิ์เดียวกับกลางวัน คนที่ไม่ได้เข้า **อยู่ที่เดิม** และได้ Command Seal หรือม้วนคาถาคืน
   - เปิดพร้อมกัน จึงไม่รู้ว่าคนอื่นจะย้ายตามมาหรือเปล่า
3. **ลงการ์ดพร้อมกัน** (20 วิ) ทุกคนที่ต้องสู้เลือกการ์ด 2 ใบแบบลับและจ่ายมานารวม (ลงคว่ำได้ = 0 พลัง ไม่เสียมานา) พร้อมกับเลือก "เพิ่มพลัง!", "รักษา!" และไอเท็มต่อสู้ในขั้นนี้เลย
4. **เปิดพร้อมกัน แล้ว server คิดผลตามลำดับนี้ในครั้งเดียว**
   1. "รักษา!" และไอเท็มฟื้น HP
   2. ทอยลูกเต๋า (รวมลูกที่ทอยเพิ่ม ข้อ 6)
   3. คำนวณพลังรวม · ถ้าใครลง NP ชื่อจริงถูกเปิดหลังคำนวณ (จุดอ่อน −2 มีผลตั้งแต่การต่อสู้ครั้งถัดไป)
   4. คิดดาเมจ แล้วเช็กว่าใครตาย
   5. แจกรางวัล ธงยึดครอง จอก และของที่ยึดจากผู้ตาย
5. **อัญเชิญใหม่อัตโนมัติ** สำหรับ Servant ที่ตาย (ข้อ 9) ไม่ต้องรอใครเลือก
6. ทิ้งการ์ดที่ใช้ (การ์ด NP กลับไปวางข้างตัว ใช้ซ้ำได้)

### 4.3 กลางคืน 2: สู้ซ้ำหลังจัดทัพใหม่
ขั้นตอนเหมือนกลางคืน 1 ทุกอย่าง (ย้าย → ลงการ์ด → เปิดผล → อัญเชิญใหม่ → ทิ้งการ์ด) ต่างกันแค่นี้:
1. **ก่อนเริ่ม:** จั่วให้มือครบ 3 ใบ · การ์ดรางวัลของกลางคืน 1 ที่ไม่มีใครได้ (มอนสเตอร์ชนะหรือไม่มีใครอยู่) ให้ทิ้ง แล้ววาง **ใบใหม่เปิดหน้า** ที่สนามรบที่เปิดอยู่ทุกแห่ง สนามรบละ 1 ใบเสมอ
2. **HP ไม่ฟื้นระหว่างเฟส** คนที่แพ้ในกลางคืน 1 ยังบาดเจ็บอยู่ ถ้ายังติดพันกับศัตรูต้องสู้ซ้ำ ทางรอดคือ "หนี!" หรือ "รักษา!" (ใช้ Command Seal) หรือไอเท็ม
3. **ติดพัน** และ **ที่ว่างของวัด/โบสถ์/คฤหาสน์** ดูจากตำแหน่งตอนจบกลางคืน 1 · ย้ายแบบจ่ายมานาได้อีกครั้ง (2 มานา)
4. **โบนัสพื้นที่ (ข้อ 6.1)** นับจากตำแหน่งตอนจบกลางคืน 1: อยู่ที่เดิม = ตั้งหลัก (หรือยึดครองถ้าถือธง) · ย้ายหรือหนีเข้ามาในกลางคืน 2 = บุกเข้ามา
5. **Master ที่ Servant ตายในกลางคืน 1:** ถูกนำออกจากพื้นที่ก่อนนับตำแหน่งเริ่มเฟสของกลางคืน 2 (ที่ว่างเพิ่มขึ้น และคู่ต่อสู้ที่เหลืออยู่คนเดียวถือว่าไม่ติดพัน) Servant ตนใหม่ (อัญเชิญอัตโนมัติตอนจบกลางคืน 1) พักฟื้นตลอดกลางคืน 2 Master ไม่อยู่ในพื้นที่ใด ไม่ต้องสู้และไม่มีใครโจมตีได้ (ธงที่ถืออยู่จึงหลุด) กลับมาเลือกพื้นที่ได้ตอนกลางวันถัดไป
   - ⚠️ เดโมตอนนี้ยังต่างจากข้อนี้: Servant ตนใหม่อยู่พื้นที่เดิมของ Master และสู้ในกลางคืน 2 ได้ (ธงไม่หลุด) จะปรับให้ตรงเมื่อสั่งแก้เกม
6. การ์ดอีเวนต์ประจำวันมีผลทั้งวัน รวมทั้ง 2 เฟสกลางคืน ธงยึดครองและจอกเปลี่ยนมือได้ทุกเฟส (ข้อ 6.1, 11)

### 4.4 หมดเวลาและหลุดจากเกม
- **ไม่เลือกภายในเวลา:** กลางวัน = สนามรบล่าสุดที่เคยอยู่ถ้ายังเปิด ไม่งั้นสุ่มสนามรบ (วันแรกสุ่มสนามรบ) และไม่ใช้ธุระโบสถ์หรือการหลอม · ย้าย = อยู่ที่เดิม · ลงการ์ด = **บอทเลือกการ์ดให้** (ไม่ใช่ลงคว่ำ) เพื่อไม่ให้เน็ตกระตุกทำให้แพ้ฟรี
- ตัวจับเวลาของ server เป็นตัวตัดสิน และรับคำตอบช้าได้อีก 1 วินาที
- **หลุดกลางเกม:** ถ้าพลาด 1 ขั้นและยังไม่กลับมา บอทเล่นแทนทันที ผู้เล่นกลับมาเมื่อไรก็ได้ เริ่มเล่นเองตั้งแต่ขั้นถัดไป
- **ตกรอบแล้ว:** ดูต่อแบบผู้ชมได้ (เห็นแค่ข้อมูลที่เปิดแล้ว) หรือออกจากห้องก็ได้ ผลอันดับแสดงตอนจบ

## 6. การต่อสู้: การ์ด + ลูกเต๋า

**พลังรวม = การ์ด 2 ใบ + โบนัสพื้นที่ + การ์ดอีเวนต์ประจำวัน + พื้นที่ถนัด (±2) + ชื่อจริงถูกเปิดแล้ว (−2) + ผู้ถือจอก (+3) + ลูกเต๋า + "เพิ่มพลัง!" (+4) + อัญมณีของโทซากะ (+4)**

- **ลูกเต๋า:** ปกติทอย 1d6 · ผลที่ให้ "ทอยเพิ่ม 1 ลูก" (จันทร์เต็มดวง, สกิลสัญชาตญาณ, เครื่องรางนำโชค) ซ้อนกันได้ ผลละ 1 ลูก แล้วใช้ลูกที่ค่าสูงสุด ระบบทอยให้อัตโนมัติ ไม่มีการทอยใหม่หลังเห็นผล
- การ์ดรางวัลให้ของ ไม่ได้เพิ่มพลัง

### 6.1 โบนัสพื้นที่และธงยึดครอง

| สถานะในสนามรบนั้น | โบนัส |
|---|---|
| **ยึดครอง:** ถือธงของสนามรบนี้ และอยู่ที่นี่ตั้งแต่เริ่มเฟส | +3 |
| **ตั้งหลัก:** อยู่ที่นี่ตั้งแต่เริ่มเฟส (รวมคนที่ถูกส่งมาจากการเกินความจุ) | +1 |
| **บุกเข้ามา:** ย้ายหรือ "หนี!" เข้ามาในขั้นย้ายของเฟสนี้ | 0 |

"เริ่มเฟส" ของกลางคืน 1 = จบกลางวัน · ของกลางคืน 2 = จบกลางคืน 1

**ธงยึดครอง** สนามรบละ 1 ผืน
- จบแต่ละเฟสกลางคืน ธงไปอยู่กับผู้ชนะที่สนามรบนั้น หรือคนที่อยู่คนเดียว
- เสมอสูงสุด: ถ้าเจ้าของธงเดิมอยู่ในกลุ่มที่เสมอ เก็บธงไว้ ไม่งั้นธงว่าง
- มอนสเตอร์ชนะ หรือไม่มีใครอยู่ตอนจบเฟส: ธงว่าง
- เจ้าของธงที่ไม่ได้อยู่สนามรบนั้นตอนจบเฟส (ย้ายออก หนี หรือพักฟื้น) เสียธง
- วัดริวโดไม่มีธงและโบนัสพื้นที่ ⚠️

### 6.2 ผลการต่อสู้

| ผล | กติกา |
|---|---|
| **ผู้ชนะ** (พลังรวมสูงสุด) | ได้รางวัลของพื้นที่ |
| **ผู้แพ้** | เสีย HP = พลังรวมของผู้ชนะ − พลังรวมของตัวเอง (ขั้นต่ำ 1) |
| **เสมอสูงสุด** | คนที่เสมอแบ่งรางวัล (ปัดขึ้น) และไม่เสีย HP · คนอื่นในพื้นที่เสีย HP ตามส่วนต่างกับค่าสูงสุดตามปกติ |
| **ฆ่าได้** | ผู้ชนะยึดมานาครึ่งหนึ่ง และการ์ดไอเท็ม 1 ใบ (สุ่ม) ของผู้ตาย · ถ้าเสมอสูงสุด ไม่มีใครยึด |

### 6.3 ตะลุมบอน (3 คนขึ้นไปในพื้นที่เดียว)
ใช้กติกาเดียวกันทั้งหมด ทุกคนลงการ์ดพร้อมกัน เทียบครั้งเดียว:
- คนที่สูงสุดชนะคนเดียว ได้รางวัล **+2 มานาโบนัส** (ถ้าเสมอสูงสุด แบ่งโบนัสด้วย)
- **ทุกคนที่เหลือ** เสีย HP ตามส่วนต่างกับค่าสูงสุด จึงอันตรายกว่าการดวล
- มอนสเตอร์นับเป็นผู้เข้าร่วม 1 ตน

| **รักษา!** | กลางวัน หรือ กลางคืน 1/2: ลงการ์ด | ฟื้น HP 50% (ถ้าเลือกตอนลงการ์ด ฟื้นก่อนคิดดาเมจ) |
| **อัญเชิญ** | อัตโนมัติเมื่อ Servant ตาย | อัญเชิญ Servant ใหม่ (ข้อ 9) |

### ธุระโบสถ์ (เลือกพร้อมกับการเลือกพื้นที่ตอนกลางวัน)
- **ถวายมานา:** แลก Command Seal 1 ดวง ราคา **5 มานา** เท่ากันทุกครั้ง (v1.3 เดิม 10 / 14 / 18) ⚠️
- **รับเควส** 1 ใน 3 ใบของวันนั้น (มัดจำ 2 มานา ทำสำเร็จได้ Command Seal ทันที ถือได้ทีละ 1 เควส · "ภายใน N วัน" นับวันที่รับเควสเป็นวันแรก หมดเวลาเมื่อจบกลางคืน 2 ของวันสุดท้าย) ⚠️
  - ล่าค่าหัว: ทำให้ Servant ตนไหนก็ได้ตาย ภายใน 2 วัน
  - ชนะสนามรบ: ชนะการต่อสู้ที่มิยามะหรือชินโตะ 3 ครั้ง ภายใน 3 วัน (อยู่คนเดียวไม่นับ)
  - ล่าวีรชนที่เปิดเผยแล้ว: ชนะการต่อสู้กับ Servant ที่ชื่อจริงถูกเปิดแล้ว ภายใน 3 วัน
  - เครื่องบูชา: มอบการ์ดไอเท็ม 2 ใบ (ทันที)
- แลกได้วันละ 1 ดวงต่อคน · ผู้ถือจอกใช้โบสถ์ไม่ได้

## 9. ความตายและการอัญเชิญใหม่

- HP หมด = Servant ตาย นับเข้าตัวนับรวม (ครบ 7 → จอกปรากฏ)
- **อัตโนมัติ:** ใช้ Command Seal 1 ดวง อัญเชิญ Servant ใหม่แบบสุ่มจากกองกลาง สำรับใหม่ มือใหม่ 3 ใบ เล่นได้ตั้งแต่กลางวันถัดไป (ตายในกลางคืน 1 = พักฟื้นตลอดกลางคืน 2 ข้อ 4.3) · ตายหลายคนในเฟสเดียวกัน server สุ่มให้ทุกคนพร้อมกัน
- ผู้ที่มี "วัตถุเชื่อมโยง": เลือก Servant 1 ใน 3 ตนที่สุ่มจากกองกลางในขั้นกลางวันถัดไป (ไม่แสดงกองทั้งหมด กันการเดาว่าใครใช้ตนไหน) หมดเวลา = สุ่ม
- ไม่มี Command Seal เหลือ → Master ตกรอบ
- มานา Command Seal และไอเท็มเป็นของ Master ยังอยู่ (ยกเว้นที่ผู้ชนะยึด)

## 11. จอกศักดิ์สิทธิ์

- ปรากฏเมื่อตายรวมครบ 7 ครั้ง (ประกาศตอนเช้าของวันถัดไป แม้ครบตั้งแต่กลางคืน 1) หรือถึงวันที่ 8 (ประกาศเช้าวันที่ 8 ทันที) · วาง **เปิดหน้า** ที่สนามรบ 1 แห่งที่ยังเปิด (สุ่ม) ทุกคนรู้ว่าจอกอยู่ไหนก่อนเลือกพื้นที่
- จบแต่ละเฟสกลางคืน จอกไปอยู่กับผู้ชนะที่สนามรบนั้น หรือคนที่อยู่คนเดียว · เสมอสูงสุดหรือมอนสเตอร์ชนะ จอกยังวางอยู่ที่เดิม
- ผู้ถือจอก: พลังรวม +3 ทุกการต่อสู้ · ต้องลงสนามรบเท่านั้น ห้ามเลือกหรือหนีเข้าวัด โบสถ์ และคฤหาสน์
- ผู้ถือจอกแพ้การต่อสู้ → จอกไปที่ผู้ชนะ · เสมอสูงสุดกับผู้ถือ → ผู้ถือเก็บจอกไว้ · ผู้ถือตกรอบ → จอกไปที่ผู้ชนะในพื้นที่นั้น
- Servant ของผู้ถือจอกตายโดยไม่มี Master ชนะคนเดียว (เสมอ หรือมอนสเตอร์ชนะ) → จอกวางเปิดหน้าที่สนามรบนั้น · Master ที่พักฟื้นถือจอกไม่ได้
- **เกมจบ** เมื่อจบกลางคืน 2 ของวันที่ 8 หรือเหลือ Master คนเดียว · ถ้าจอกปรากฏเพราะตายครบ 7 ครั้ง เกมจบเมื่อจบกลางคืน 2 ของ **วันถัดจากวันที่ประกาศจอก** (แย่งจอกได้ 2 วัน = 4 เฟสกลางคืน) แต่ไม่เกินวันที่ 8 ⚠️
- **v1.2:** ตายบ่อยขึ้นจึงตายรวมครบ 7 ครั้งเร็วขึ้น จากการจำลอง จอกประกาศเฉลี่ยราววันที่ 4–5 และเกมจบราววันที่ 5–6 ⚠️
- **ผู้ชนะ** = ผู้ถือจอกตอนเกมจบ ถ้าไม่มี ผู้มีมานามากสุดชนะ

## 12. บอท

บอทใช้ **ข้อมูลเดียวกับที่ผู้เล่นคนนั้นเห็น** เท่านั้น (ไม่อ่านการ์ดคว่ำ มือคนอื่น หรือคำตอบที่ยังไม่เปิด) และทำตามข้อจำกัดเดียวกับผู้เล่น

- **กลางวัน:** เลือกจากพื้นที่ที่ยังเปิดเท่านั้น · มานา < 8 → วัด · Command Seal น้อยกว่า 3 และมานา ≥ 5 → โบสถ์ (ถวายมานา) · มีการ์ดพลัง 1–2 ในมือ 2 ใบขึ้นไปและคฤหาสน์เปิด → คฤหาสน์ (หลอมใบพลังต่ำ) · ผู้ถือจอก → สนามรบเสมอ · อื่นๆ → สนามรบที่รางวัลดีและเป็นพื้นที่ถนัด (ไม่ทุกครั้ง กันถูกจับทาง) · เลือกสนามรบสำรองทุกครั้งที่เลือกวัด โบสถ์ หรือคฤหาสน์
- **กลางคืน:** ย้ายเฉพาะตอนไม่ติดพัน และสนามรบอีกแห่งดูอ่อนกว่า (ประเมินจาก HP มานา และคลาสที่เห็น) · ลงการ์ดคู่ที่พลังสูงสุดที่จ่ายไหว · ใช้ NP เมื่อประเมินว่าโอกาสชนะสูง หรือเป็นการต่อสู้ชิงจอก · ใช้ "เพิ่มพลัง!" เมื่อชิงจอก · ใช้ "หนี!" เมื่อ HP ต่ำมากและเหลือ Command Seal ≥ 2 · กลางคืน 2: ถ้าบาดเจ็บหนักและยังติดพันกับคนที่เพิ่งชนะตัวเอง ให้ใช้ม้วนคาถาเคลื่อนย้ายหรือยาสมานแผลก่อน ถ้าไม่มีและเหลือ Command Seal ≥ 2 จึงใช้ "หนี!" หรือ "รักษา!" (ไม่ใช้ดวงสุดท้าย) · ถ้าอยู่คนเดียวและมีศัตรูบาดเจ็บในสนามรบอื่น ให้ย้ายไปไล่ล่า
- **ระดับยาก:** จำการ์ดที่คู่แข่งลงเพื่อเดาตัวตนและพื้นที่ถนัด
- **เล่นแทนคนที่หลุด** ด้วยกติกาเดียวกัน

## 13. สถาปัตยกรรมเครือข่าย

- Node.js server ถือสถานะทั้งหมด ทอยลูกเต๋า สับการ์ด จับเวลา รันบอท · client (Vite) แสดงผล ส่งแค่การเลือก
- **ทุกขั้นเลือกพร้อมกัน** มีตัวจับเวลาเดียวต่อขั้น server รับคำตอบลับจนครบหรือหมดเวลา แล้วเปิดผลทีเดียว (ไม่มีการรอเทิร์น ไม่มีช่วงแทรกหลังเปิดผล)
- **ข้อมูลลับไม่ส่งไปที่ client:** การ์ด Servant ที่คว่ำ, การ์ดในมือคนอื่น, การ์ดรางวัลคว่ำ, คำตอบของทุกขั้นก่อนเปิดผล (พื้นที่ สนามรบสำรอง ธุระโบสถ์ การ์ดที่หลอม การย้าย การ์ด ไอเท็ม Command Seal), พื้นที่ถนัด, เควสที่คนอื่นถือ
- **ข้อยกเว้น:** มือของเป้าหมายส่งให้คนในโบสถ์คนเดียว · การ์ด Servant ของเป้าหมายส่งให้คนที่ใช้บันทึกวีรชนคนเดียว
- ผู้ชมที่ตกรอบเห็นเฉพาะข้อมูลที่เปิดแล้ว
- `ws` + JSON · โครงสร้าง `client/`, `server/`, `shared/` (servants, cards, areas, situations, events)

### 13.1 หน้าจอ
- แถบวันด้านบนแสดงวันที่และเฟสปัจจุบัน (กลางวัน / กลางคืน 1 / กลางคืน 2)
- **แผนที่ตรงกลางห้ามมีอะไรทับกัน:** พื้นที่ 5 แห่งเป็นกล่องแยกกันมีระยะห่าง (เช่น ผังกากบาท) ป้ายชื่อเมืองหรือวันที่ไม่วางทับกล่อง ไอคอน Servant และชื่อ Master อยู่ในกล่องของพื้นที่ตัวเองเท่านั้น ถ้าคนเยอะให้ขึ้นแถวใหม่หรือย่อไอคอน ห้ามล้นออกนอกกล่องหรือตัดชื่อจนอ่านไม่ออก ป้ายบนกล่อง (ความจุ ธง การ์ดรางวัล จอก มอนสเตอร์) อยู่ในกล่องเดียวกัน
- ต้องไม่ทับกันทั้งบนจอคอมและจอมือถือ

- โบนัส "คนมาก่อน +3/+1" เปลี่ยนเป็น ยึดครอง +3 / ตั้งหลัก +1 / บุกเข้ามา 0 พร้อมธงยึดครอง
- พื้นที่เกินความจุ: มานาน้อยสุดได้ก่อน (วัด) · Command Seal น้อยสุดได้ก่อน (โบสถ์) · คนที่ไม่ได้เข้าไปสนามรบสำรอง
- ทุก Command Seal ไอเท็ม และสกิล มีขั้นที่ใช้ชัดเจน ไม่มีการตัดสินใจหลังเห็นผล · "ทอยใหม่" เปลี่ยนเป็น "ทอยเพิ่ม 1 ลูก ใช้ค่าสูงสุด"
- อัญเชิญใหม่อัตโนมัติ · กติกาหมดเวลา หลุดกลางเกม และผู้ชม
- จอกวางเปิดหน้าเสมอ · กติกาเสมอของรางวัล ธง และจอก · เควส "เปิดโปงวีรชน" เปลี่ยนเป็น "ล่าวีรชนที่เปิดเผยแล้ว"
